# NPC Dialogue Lab

NPC가 긴 대화와 행동을 이어 갈 때 캐릭터성과 세계 설정을 유지하는지 비교하는 로컬 실험 도구입니다. 웹과 CLI가 같은 실행 엔진을 사용하며 대화, 수신 기록, 평가, 토큰, 응답 시간, API 환산 비용을 SQLite에 저장합니다.

현재 문서는 **앱 1.4.0 · 설정 schemaVersion 1** 기준입니다. Node.js 24 이상, TypeScript, React, Fastify, SQLite를 사용하며 Windows·한국어 환경을 우선 지원합니다.

Codex 테스트 세션은 완료·중단 또는 일회성 호출 종료 후 자동 정리합니다. 기존 기록의 정리 명령과 일시정지 예외는 [세션 정리 정책](docs/codex-session-cleanup.md)을 참고하세요.

## 시작하기

프로젝트 폴더에서 설치하고 빌드합니다.

```powershell
npm ci
npm run build
```

실행 경로 중 하나를 선택하세요. 여러 서버를 함께 띄우려면 포트와 데이터 폴더를 분리합니다.

| 경로 | 실행 명령 | 주소 / 기본 저장소 |
|---|---|---|
| Codex CLI | `npm run cli -- serve --adapter codex --port 4317` | `http://127.0.0.1:4317` / `data/` |
| OpenAI API | `npm run start:openai` | `http://127.0.0.1:4318` / `data/openai/` |
| 모의 실행 | `npm run cli -- serve --adapter mock --port 4319 --data data/mock` | `http://127.0.0.1:4319` / `data/mock/` |

Codex 경로는 설치·로그인된 Codex CLI가 필요합니다. API 경로는 페이지의 **API 키 설정**에서 개인 키를 입력하거나 서버 환경 변수·로컬 `.env`에 `OPENAI_API_KEY`를 설정합니다. 새 실험은 해당 브라우저의 개인 키를 우선하고, 없으면 서버 환경 키를 사용합니다. 둘 다 없으면 키 입력을 안내합니다. 개인 키는 서버 메모리에만 보관하므로 서버 재시작 후 다시 입력합니다. 키를 실험 JSON에 넣지 마세요. [API 실행 안내](docs/openai-api.md)에서 적용 범위·복구 방법을 확인할 수 있습니다. 모의 실행은 실제 모델을 호출하지 않으며 품질 비교용 결과가 아닙니다.

브라우저에서 **새 실험**을 열어 예제를 불러오고 모델·추론·조건을 검증한 뒤 생성합니다. 전체 JSON과 세계관·선택 캐릭터·전체 캐릭터·실험 조건 JSON을 각각 편집할 수 있습니다. 생성된 묶음의 설정은 스냅샷으로 고정됩니다. 브라우저를 닫아도 서버가 켜져 있으면 실행과 저장은 계속됩니다.

## 실험 환경

| 환경 방식 | 진행 | 시작 예제 |
|---|---|---|
| `off` | 대화·행동 의도 표현. 별도 세계 결과 판정 없음 | [간단한 전달 비교](examples/quick-check.json) |
| `rules` | 사전에 작성한 행동 조건·상태 효과·목표로 결과 확정 | [작성용 예제](examples/authoring-starter.json) |
| `ai` | 단일 공간에서 NPC 선택마다 AI가 물리 결과·가상 시간·지연 사건 처리 | [세계 엔진 예제](examples/ai-world-engine.json) |
| `ai_spatial` | 장소별 대화·혼자 행동·이동·귓속말·원격 채널, 겹치는 가상 시간 | [분산 공간 예제](examples/spatial-world.json) |

AI 환경에는 빈도·강도·금지 범위를 지정한 **상황 발생 엔진**도 선택적으로 붙일 수 있습니다. 엔진이 NPC의 자발적 행동·내면을 대신 결정하지 않으며 즉각 반응이 필요한 대상에게 선택 기회를 제공합니다. 동작과 한계는 [세계 엔진·분산 공간](docs/world-engine.md)을 참고하세요.

모델·추론·기억·전달·환경 방식을 조건별로 비교하고 반복 실행할 수 있습니다. **모아 전달**은 다음 차례에 수신함을 전달하고, **매 발화 전달**은 다음 발화 전에 실제 수신자에게 확인 호출을 합니다. 발화와 동시에 확정된 규칙 결과는 순서대로 한 호출에 함께 전달합니다. 기본 설정은 60차례·동시 묶음 2개·10차례마다 평가입니다. API 서버의 일반 새 예제는 최대 18차례이며 분산 공간 예제와 불러온 파일의 실행량은 별도로 확인해야 합니다.

## 기록과 분석

- 원본 시나리오·최종 NPC 설정, 대화·행동·관찰 범위, 세계 상태·상황 제안을 실행별로 보존합니다.
- 캐릭터·세계관 이탈, 의미 반복·목표 정체를 AI가 평가하고 사람의 확정·기각·메모를 별도로 남깁니다. 어휘 반복률과 규칙 모드의 목표 달성도 집계합니다.
- 여섯 종류의 모델 호출과 실패·재시도를 구분해 토큰·시간·USD 환산 비용을 표시합니다. 비용은 저장된 단가 기준 추정치입니다.
- 여러 저장 위치의 Codex·API·모의 기록을 한 화면에서 조회·필터·비교합니다. 삭제 전 범위와 개수를 확인하며 개별·일괄 영구 삭제를 지원합니다.
- JSONL, CSV, 설정 JSON, Markdown 대화록을 ZIP이나 폴더로 내보냅니다.

## 문서

자연스러운 반응을 위한 공통 지침은 [대화 프롬프트 버전과 검증](docs/dialogue-prompts.md)에서 관리합니다. 실험 조건의 **대화 반응 지침**으로 이전 버전과 비교할 수 있습니다. 일상 대화는 [거실에서 고르는 영화](examples/natural-dialogue.json) 예제로 시작할 수 있습니다.

인물마다 비슷하게 말하는 문제는 [인물별 말투 비교 기록](docs/reviews/character-voice-2026-11-07/report.md)에 별도로 정리했습니다. 기본 지침은 v5이며, v6~v9는 개선 근거가 부족해 실험 선택지로만 남겨 둡니다.

후속 [프로필·발화 방식 비교](docs/reviews/profile-voice-2026-11-07/report.md)는 공통 문단 제거, 고유 예문 보강, 말투 편집과 생활극 집필 틀의 결과를 보존합니다. 원본 인물 설정을 유지하며 효과가 불분명한 후보는 기본값으로 적용하지 않습니다.

[진행자 v4](docs/reviews/director-context-2026-11-07/report.md)는 공개 시작 장면을 참고해 질문 상대를 고릅니다. 고지서 주인을 모르고 동행을 반복 선택하던 문제를 고쳤으며, 비공개 인물 설정과 다른 장소의 장면은 전달하지 않습니다.

[기본 예제 안정화](docs/reviews/harbor-stability-2026-11-07/report.md)는 인물 프로필 v2에서 반복 요약·정형 몸짓을 줄입니다. 새 OpenAI 예제의 NPC는 사용 가능한 Sol을 우선하며 진행자·평가자는 Luna를 사용합니다. 최대 18차례 안에서 목표를 달성하면 끝나고, 저장된 설정은 유지합니다. 한국어 유지 후보 v10은 연속 대화에서 실패해 실험으로만 보존합니다.

[윤·미루 후속 비교](docs/reviews/harbor-refinement-2026-11-07/report.md)에서는 성격을 유지하며 잡담 뒤 임무 언급과 공유된 설명의 반복을 줄인 인물 프로필 v4를 새 기본값으로 채택했습니다. v3의 부작용, 동일 조건의 실제 대화, 남은 말투 유사성도 기록했습니다. 공통 지침 v5와 모델 설정은 유지합니다.

기존 저장 설정을 쓰고 있다면 [v4 예제](examples/harbor-profile4.json)를 실험 편집기의 JSON 파일 가져오기로 불러올 수 있습니다.
