# 서월 인물 프로필·발화 방식 비교 · 2026-11-07

사용자의 우선 피드백은 **인물마다 성격과 말투가 비슷하다**는 점이다. 공통 NPC /6~ /9 실험 다음으로 프로필만 비교했지만, 이번 후보도 기본값으로 채택할 정도의 일관된 개선은 확인하지 못했다. 원본 프로필 /1과 NPC /5를 유지한다. 인물성이 충분하다는 뜻은 아니다.

## 남은 문제

맡기로 하지 않은 서류 접기를 방문객이 당연히 넘기는 장면에서 /3의 다섯 인물 모두 “잠깐만요”로 시작했다. 유진의 “저 이거 맡겠다고 한 적 없어요. 쉬고 있는 거예요.”와 하린의 “저 이거 맡겠다고 한 적 없어요. 두고 가지 마세요.”는 타당하지만 구별되는 리듬의 근거는 약하다. 같은 거절을 억지로 뒤집어 차이를 만들지는 않았다.

대신 골라 준 첫 곡에 대해 다섯 인물이 두 번째 곡을 원했다. 하린이 저음과 박자에 말을 더 보태기는 했지만 다른 인물도 비슷한 요청 형태를 보였다. 생활극 집필 틀에서도 세림·태경은 두 번째가 더 좋다는 말 뒤에 틀어 달라는 요청으로 모였다.

보류 상황의 짧은 “잘 먹을게요”는 자연스럽게 겹칠 수 있다. 연우의 /3 “문 잠깐 잡아 드린 건데, 과자까지 받아도 돼요?”는 호의를 정산하려는 성격과 연결되지만 /2에서도 호의의 크기를 되짚었다. 갑자기 붙는 관리비를 확인하는 공통 질문도 그 자체로 결함은 아니다. 단어·어미 차이를 후보 전반의 개선으로 세지 않았다.

긴 대화의 /3 하린은 고지서 #8에서 “그거 적고 나면 저녁 먹으러 가요. 저는 따뜻한 국물 먹고 싶어요”라고 자기 관심을 꺼냈다. /1에서는 #15에 배고픔을 말했다. 반송 /3 태경은 “띠 사러 따로 왕복해야 해요. 8만 원은 받아야겠어요”라고 자기 부담을 짚었고, /1도 “밀린 돈 받는 게 왜 깎을 조건입니까”라는 고유 입장이 나왔다. 각 한 번의 세계 판정·화자 선택 경로와 얽혀 있어 프로필 효과로 단정하지 않았다.

72개 프로필 쌍과 30개 추가 생성 비교의 원문·판정은 [judgments.json](judgments.json)에 있다. 작성자가 매핑을 알고 평가한 **비독립 에이전트 검토**다. `tie`는 채택 근거 부족이며 목표 달성을 뜻하지 않는다. 독립 사람 평가·인간 동등성·통계적 우월성을 주장하지 않는다.

## 별도로 발견한 연결 문제

고지서 /1에서 유진의 #1 질문 뒤 #2~#5가 무언·무동작이었다. [진행자 호출](profile1-maintenance/calls.jsonl)에는 이름과 최근 발언만 있고 **연우가 고지서를 가져왔고 하린은 동행이라는 시작 장면이 없었다.** 진행자는 하린을 당사자로 잘못 판단하고 유진과 하린을 반복 선택했다. 연우는 강제 대기 순서가 적용된 #6에서야 답했다.

이는 문체와 구별되는 입력 누락이다. 후속 진행자 /4 수정은 NPC들이 이미 공유하는 시작 장면을 한도 안에서 전달한다. 비공개 프로필·세계 판정 자료·다른 공간의 장면을 전달하지 않는다. 결과는 별도 진행자 보고서에서 다룬다.

## 재현·검증

명령과 평가 기준은 [profile-review.md](../../../evals/dialogue/profile-review.md)에 있다. 각 폴더에 당시 사례, 프로필, 정책, 실제 요청·출력·사용량과 해시를 보존했다. 긴 대화는 설정, 모든 호출, 세션 지침, 대화 원문을 남겼다. API 키·공급자 원시 이벤트·로컬 DB는 보관 대상이 아니다.

- 보관 자료 71개 해시·크기 일치, 174개 고정 입력/프로토타입 요청 해시 일치.
- 현재 코드로 프로필 비교의 실효 요청 144개를 바이트 단위로 재현하고, 102개 비교 인용을 원문과 대조했다.
- 긴 대화 호출을 포함해 총 385개 호출의 수와 세션 지침 해시를 확인했다.
- 타입 검사·빌드·전체 테스트 **180/180 통과**. 전체 검사에는 후속 진행자 /4 코드가 포함되어 있다. 프로필 전용 3개 검사도 별도 통과했다.
- 생성 에셋의 인물 설정과 기본 NPC /5는 변경하지 않았다. 이 검증은 모델의 인간 동등성을 증명하지 않는다.
