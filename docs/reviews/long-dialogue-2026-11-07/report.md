# 긴 대화의 연속성과 조용한 시간

2026-11-07. NPC /5는 유지하고, 진행자 /3과 세계 /6을 적용한다. **실행이 끝났다는 사실과 자연스러운 대화라는 판단을 구별한다.** 세계 /4로 완료된 48차례 실행도 마지막 23차례 동안 가상 시간이 멈춰 있었으므로 품질 성공으로 세지 않는다.

작성자가 원문을 읽은 비독립 검토다. 사람 평가나 사람과의 동등성을 입증한 결과는 아니다. 사용자는 이번 검토 중 다음 우선순위를 **인물마다 성격과 말투가 비슷해지는 문제**로 정했다. 아래 수정은 대화가 진행될 기반을 고친 것이며 그 구별성 문제의 해결을 주장하지 않는다.

## 실제로 확인한 실패와 수정

| 실제 실패 | 처리 | 보존한 경계 |
|---|---|---|
| 진행자 /2가 `allowedSpeakerIds`에 고복만만 있는데 임소진을 선택, 5차례 뒤 정지 | /3에서 실제 후보를 출력 스키마 enum으로 제한. 지침 본문은 그대로 | 기존 후보 선정·장기 배제 방지·즉각 반응 우선권, 최종 런타임 ID 검사 |
| 세계 /4가 노래 신청과 질문을 반응 사건으로 만들고 현재 화자에게 다시 반응을 요청, 30차례 뒤 정지 | /5에서 대화와 물리·외부 사건 구별. /6이 이 변경을 계승 | 타인의 행동 대행 금지, 현재·기반응 화자 재요청 금지 |
| 진행자만 고친 48차례 실행에서 26~48차례가 무언·무동작, 매 세계 호출이 0초. 시계가 76초에 머무름 | /6에서 조용한 선택마다 가상 시간 1초. 시작 시 이미 진행 중인 영상·타이머 추적 | NPC에게 억지 대사·행동을 만들지 않음. 기한 전 결과 확정 금지 |

시간 규칙은 문구만의 효과가 아니다. `/6`의 무언·무동작 차례는 `elapsedSeconds:1` 스키마와 런타임 검증을 함께 사용한다. 0초·2초·120초를 거부하고, 스키마를 무시한 공급자 결과는 적용 전 정지한다. 재개는 기존 NPC 선택을 재생성하지 않고 실패한 세계 호출만 처리한다. 이전 정책·알 수 없는 저장 지침은 기존 계약을 유지한다.

세계 /5는 단독 기본값으로 채택하지 않는다. /4의 시계 정지를 확인한 뒤 /6으로 보완했다. /1~ /6의 본문 해시는 테스트로 동결한다. 실제 세션 지침, 요청별 스키마 해시와 원문은 이 폴더의 자료에 남긴다.

## 고정 입력 비교

| 세트 | 비교·호출 | 확인 결과 |
|---|---|---|
| 진행자 실제 입력 2개 × 5회 | /2 대 /3, 20회 | 두 후보는 양쪽 5/5 준수. 단일 후보는 /2 0/5, /3 5/5 준수 |
| 대화 사건화 실제 입력 4개 × 3회 | 세계 /4 대 /5, 24회 | 구조·기존 검증 모두 통과. /5는 새 대화 반응 사건 0/12. /4는 불필요한 새 사건 1/12 |
| 기존 관찰 회귀 14개 × 2회 | /4 대 /5, 56회 | 모두 검증·공개 사건 유무 기준 통과 |
| 조용한 시간 6개 × 3회 | /5 대 /6, 36회 | /6의 완전 침묵 15/15가 1초. 14초 도착 답장은 /5 1/3, /6 3/3. 이전·이후 시점에는 조기·중복 알림 없음 |
| 기존 관찰 회귀 14개 × 2회 | /4 대 /6, 56회 | 모두 검증·공개 사건 유무 기준 통과. 손상·충전·마감 취소·외부 답장·공의 반응 기회 유지 |
| 대화 사건화 실제 입력 4개 × 2회 | /4 대 /6, 16회 | 모두 검증 통과. /6은 새 대화 반응 사건 0/8. 영상 재생 과정은 별도 추적 |

`observations.json`의 예전 holdout도 재사용했으므로 이번에는 회귀 검사다. 조용한 영상 입력 하나와 대화 사건화 입력은 실제 실행에서 추출했고, 나머지 조용한 시간 사례는 합성 경계 검사다. 참고 판정 기준은 모델에 전달하지 않았다. 고정 입력은 독립 새 세션이므로 기존 세계 세션의 누적 대화 전체까지 재현한 것은 아니다.

공개 사건 수만으로 의미를 판단하지 않았다. 거절은 계약 성립으로 만들지 않았고, 공을 받은 것으로 타인의 선택을 대신하지 않았다. /6의 뜨거운 물 표본에서는 식는 과정을 추가했고 한 표본은 마신 양까지 재서술했다. 이런 세부 판정의 양과 임의로 추정한 재생 길이는 여전히 다듬을 여지가 있다.

## 일상 대화 8개, 총 288차례

친구의 도자기 사진과 직장 동료의 점심이라는 두 새 장면을 NPC /3·/5 각각 2회, 회당 36차례로 실행했다. 모델은 `gpt-6.1-sol / low`, 세계 꺼짐, 순번제, 새 NPC 세션이다. 두 버전 모두 4/4 실행 완료이며 같은 데이터·예정 사건을 사용했다.

- 점심 /5의 두 실행은 오전 실수를 잠깐 이야기한 뒤 산책·야구·음식으로 넘어갔다. 회의가 두 시에서 세 시로 바뀐 알림도 21~23차례에 반영했다. 이미 고친 숫자를 다시 수리하는 장면으로 되돌리지 않았다.
- /5 점심 1회의 지은은 야구 대화 중 10차례에서 아무 말·행동을 만들지 않았고, 16차례에서 “그렇게 이기고 있으면 기분 좋아서 끝까지 보게 되는 거 아니에요?”로 다시 참여했다. 침묵을 영구 이탈로 해석하지 않았다.
- /3도 대체로 문맥에 맞게 이어졌다. 두 버전 모두 비슷한 동의·질문 패턴과 음식 조리 설명, 컵 손잡이 농담 연쇄가 남았다. 이 세트만으로 /5가 인물 구별성을 개선했다고 주장하지 않는다.
- /5 점심 1회의 은서는 오후 회의에도 수정한 표를 쓸 것처럼 말했다가 지은의 정정을 받아들였다. 실제 모르는 정보에 대한 추측과 정정이 있었음을 남긴다. 원래 팀·책 제목 등 미지정 개인 세부사항을 생성한 경우도 있으므로 엄격한 설정 고정이 필요한 프로젝트에는 별도 경계 검토가 필요하다.
- 식사 후 산책을 약속했지만 36차례 한도에서 아직 식사를 끝내는 중인 실행도 있다. 그 약속의 최종 실행까지 검증했다고 쓰지 않는다.

## 서월 48차례 비교

인물 프로필과 시작 장면은 기존 `strong-voices-dinner.json`을 그대로 사용했다. NPC는 Sol low, 세계는 Luna medium, 진행자는 Luna low다. 실패한 기존 두 실행은 자동 재시도하지 않았고 정지한 원문을 보존했다.

세계 /4·진행자 /3의 실행은 48차례를 완료했지만 영상 종료를 처리하지 않았다. 세계 /6의 이어지는 실행에서는 영상이 끝난 관찰을 NPC가 받은 뒤 다음 곡을 찾아 재생했다. 초기 영상의 남은 길이가 원본에 없어서 종료 시각은 세계 모델의 추정이다. 음악을 감상하며 한동안 말하지 않는 것은 자체로 오류가 아니며, 조용한 차례에도 시간이 흘렀는지를 따로 본다.

| 세계·진행자 | 결과 | 조용한 선택 | 최종 가상 시간 |
|---|---|---|---|
| /4·/3 | 48차례 완료, 영상 종료 미처리 | 23차례 모두 0초 | 76초 |
| /6·/3 반복 1 | 48차례 완료, 영상 종료 후 다음 곡 재생 | 20차례 모두 1초, 최장 연속 16차례 | 102초 |
| /6·/3 반복 2 | 48차례 완료, 영상 종료 후 다음 곡 재생 | 15차례 모두 1초, 최장 연속 9차례 | 114초 |

두 /6 실행 모두 후속 노래가 아직 재생 중인 상태에서 발화 한도에 도달했다. 이후 곡의 종료까지 확인한 것은 아니다. 반복 2는 조용히 듣다가 도하가 38차례에 다시 곡 취향을 묻는다. 이때 복만은 빵을 먹으려는 자기 의사를 유지한다. 다만 두 반복에서 비슷한 ‘따라 불러 봐 / 빵 먹는데 무슨 노래냐’ 구성이 나왔으므로 표현의 다양성과 성격 구별성은 다음 비교 대상으로 남긴다.

최종 호출 수·비용·실행 상태·침묵 수·세계 시계는 [manifest.json](manifest.json)의 실측값이다. 비용은 계정 잔액 조회가 아닌 로컬 가격표와 API 보고 사용량에 따른 추정이다. `calls.jsonl`은 필수 입출력·계측·버전만 보존하며 공급자 원시 스트림·인증 데이터는 공개 자료에서 제외했다. `instructions.json`은 실제 저장된 역할 지침이다. 대화 본문은 그대로이며 파일 끝 빈 줄만 정리했다.

이번 보고서의 실제 API 호출은 총 **1,017회**, 가격표 추정은 **$1.081147025**다. 실패한 실행과 대조군도 포함하며 이전 보고서의 호출을 다시 합산하지 않았다. NPC는 `gpt-6.1-sol`, 세계·진행자는 `gpt-6-luna`라는 실제 응답 모델을 기록했다.

## 재현

```powershell
npm run director:eval -- --live --repetitions 5 --max-calls 20 --max-usd 1
npm run world:eval -- --cases evals/world/dialogue-processes.json --baseline npc-world/4 --candidate npc-world/5 --split all --repetitions 3 --max-calls 24 --max-usd 1 --live
npm run world:eval -- --cases evals/world/quiet-time.json --baseline npc-world/5 --candidate npc-world/6 --split all --repetitions 3 --max-calls 36 --max-usd 1 --live
npm run world:eval -- --baseline npc-world/4 --candidate npc-world/6 --split all --repetitions 2 --max-calls 56 --max-usd 1 --live
node --env-file-if-exists=.env --import tsx scripts/dialogue-soak.ts --specs evals/dialogue/long-conversations.json --baseline npc-dialogue/3 --candidate npc-dialogue/5 --turns 36 --repetitions 2 --max-calls 288 --max-usd 2 --live
npm run seowol:live -- --spec assets/seowol/experiments/strong-voices-dinner.json --policy npc-dialogue/5 --world-policy npc-world/6 --model gpt-6.1-sol --turns 48 --repetitions 2 --max-calls 286 --max-usd 1 --label dinner-v5-world6 --live
```

각 비교는 같은 입력에서 새 세션을 만든다. 결과 문장이 그대로 재현된다는 보장은 아니다. `--live`를 빼면 유료 요청 없이 계획을 확인할 수 있다.
