# 짧은 캐릭터 설정으로 생성한 대화 비교

새 실행의 기본값은 `character-performance/2`다. 인물 설정에 같은 연기 지시를 반복해서 쓰던 부분을 엔진으로 옮겼다. 일반 대화 지침은 `npc-dialogue/5`를 사용했다. 실제 출력에서는 일상 질문에 본래 과제를 덧붙이는 일이 줄어든 사례가 있었다. 같은 해요체를 쓰는 인물의 문장 박자는 여전히 비슷해지는 경우가 있었다.

## 변경 이력

| 버전 | 이유와 동작 |
| --- | --- |
| 기존 방식 `off` | 작성한 프로필과 세션의 실제 대화 이력으로 연기한다. 새 필드 도입 전 저장한 실행도 이 방식으로 재개한다. |
| `character-performance/1` | 첫 발화의 구조화 응답에 관심의 방향과 말의 박자를 함께 선택하게 했다. 검증된 발화를 저장하는 트랜잭션에서 두 값을 인물별로 저장한다. 개발 장면의 네 인물 모두 ‘대답을 먼저 건넨다’를 골랐다. |
| `character-performance/2` · `npc-lab/11` | 말투·예문과 양립하는 박자가 여럿이면 참가자 순서에 따른 제안을 출발점으로 사용한다. 상대가 이전 화제로 돌아오고 낱말이 겹칠 때 본인의 확정된 발언 한 줄을 참조할 수 있다. 직접 들을 수 있었던 마지막 말·상황을 기준으로 최근 자기 발화 최대 32개에서 찾고, 장문의 발언과 귓속말·채널 발언은 인용에서 제외한다. |
| `harbor-profile/5` | 새 등대 예제에서 잡담을 일로 돌리지 않기, 같은 이유와 동작을 되풀이하지 않기를 공통 처리로 이전했다. 목표·말투·행동 세 필드의 합계가 윤 455→126자, 도하 325→126자, 미루 552→125자가 됐다. 개인 성격과 예문은 그대로다. |
| `experiment-authoring/2` | JSON 작성 지침과 편집기가 이름·ID만 있는 인물을 받는다. 새 NPC를 추가하면 비어 있는 프로필로 시작한다. |

개인 설정이 하나라도 있으면 모델이 그 설정에서 두 항목을 고른다. 선택지가 맞지 않는 외부 응답에서는 유효한 발화와 작성자 설정을 사용한다. 이름만 있는 인물에는 참가자 순서로 두 항목을 정해 같은 실행에서 유지한다. 엔진이 저장하는 값의 범위에는 전기, 사건, 지식, 관계, 존대 여부가 없다. 발화 이외의 모델 호출은 추가되지 않았다.

## 실제 조건과 원문

OpenAI API의 `gpt-6.1-sol`, 추론 `low`, 고정 순서, 배치 전달, 세계·평가자 꺼짐으로 실행했다. 장면·인물·시작 순서·2차례의 예정 사건은 쌍별로 같았다. 각 조건은 독립 세션이므로 첫 발화 이후 상대에게 전달되는 대화는 달라진다. 이관 비교만 프로필까지 함께 교체했다. 모델이 선택한 비공개 항목 수를 인물 구별성 점수로 사용하지 않았다.

| 비교 | 실제 호출 | 원문·행동·호출 기록 |
| --- | ---: | --- |
| 초기판 /1, 개발 2장면 × 6차례 × 2조건 | 24 | [초기판](development-v1.json) |
| /2, 같은 개발 2장면 × 12차례 × 2조건 | 48 | [긴 대화](development-v2.json) |
| /2, 개발에 쓰지 않은 부엌·인쇄소 × 2회 × 6차례 × 2조건 | 48 | [보류 장면](holdout-v2.json) |
| 기존 등대 프로필 /4와 엔진을 끈 조건, 간략화한 /5와 /2 엔진 조건 | 12 | [기본 예제 이관](harbor-migration.json) |
| 프로필을 이름과 ID로만 채운 극장 장면 | 12 | [이름만 입력](names-only.json) |

모두 합해 144회, 실행 당시 카탈로그 기준 추정 비용은 약 USD 0.372였다. 아래 대사는 원문 그대로 발췌했다. 사건과 무언 행동을 포함한 전체 순서는 표의 JSON에서 읽을 수 있다.

### 윤과 미루가 근무 전에 빵을 고를 때

| 짧은 동일 프로필 | 윤 | 미루 |
| --- | --- | --- |
| 기존 | 저는 통밀빵으로 할게요. 밤 근무 전에 든든하게 먹고 싶어요. | 그럼 저는 잼빵 먹을게요. 근무 전에 단 게 좀 당기네요. |
| /2 | 저는 통밀빵으로 할게요. 지금은 달지 않은 게 당겨요. | 저는 잼빵이 당겼는데, 잘됐네요. |

기존에는 두 사람이 모두 빵을 근무와 연결했다. /2에서 윤은 지금 먹고 싶은 것을 골랐고 미루는 서로 원하는 빵이 달랐다는 데 반응했다. 뒤의 음악 질문에서는 윤이 “지금 크기가 좋아요. 더 키우지는 말아 주세요.”, 미루가 “저도 지금 정도가 좋아요. 빵 먹으면서 듣기 좋네요.”라고 했다. 미루의 호기심을 매번 질문으로 표현하지 않아도 장면이 이어졌다. 다만 “당겨요”와 “당겼는데”가 연달아 나오고, 두 인물 모두 비슷한 동의 문장으로 음악에 답한다.

### 인쇄소 주인이 사진 이야기를 끊고 난방을 물을 때

| 첫 번째 보류 반복 | 승아 | 건우 |
| --- | --- | --- |
| 기존 | 네, 조금만 줄여 주세요. 저는 좀 덥네요. 건우 씨, 저는 얼굴이 잘 보이는 것보다 그때 비가 왔다는 게 남아 있는 쪽에 더 마음이 가요. | 저는 흐린 얼굴이 먼저 걸려서 비는 뒷전이었어요. 승아 씨 말 듣고 보니 빗방울도 다시 보게 되네요. 그래도 걸어 두고 싶은 건 선명한 쪽이에요. |
| /2 | 저는 조금 줄여 주시면 좋겠어요. 손은 다 녹았어요. | 저도 조금 덥네요. 줄여 주셔도 괜찮아요. |

다시 사진을 보여 주자 승아는 빗방울 얼룩을, 건우는 표정이 보이는 사진을 골랐다. 두 번째 반복에서는 기존 방식도 난방 질문에만 답했다. /2의 “손은 다 녹았어요”에는 장면에 명시되지 않은 직전 몸 상태가 들어갔다.

### 이름만 입력했을 때

| 극장 좌석 | 한결 | 은서 |
| --- | --- | --- |
| 기존 | 저는 앞줄로 살까 해요. 취소표 기다리다 시작 놓치기는 싫어서요. 은서 씨는요? | 저도 앞줄로 할게요. 기다리면서 시간 신경 쓰는 것보다는 낫겠어요. |
| /2 | 저는 앞줄은 목이 불편해서요. 취소표 조금만 기다려 볼래요. | 저는 앞줄도 괜찮아서 먼저 살게요. |

음료 이야기가 끝난 뒤 /2의 한결은 “저는 조금 더 기다릴게요.”, 은서는 “네, 앞줄 한 장 주세요.”라고 답했다. 둘이 같은 선택을 하는 것도 가능한 장면이다. 한 번의 결과로 이름만 있는 인물의 말투가 늘 구별된다고 판단할 수는 없다.

## 남은 한계와 재현

부엌에서는 재우가 “간이 좀 덜 됐네. 소금 좀 줘.”, 나리가 “여기.”로 받아 가족 간의 짧은 대화가 나왔지만, 다른 반복에서 둘 다 소금 넣은 일을 어머니께 다시 설명했다. 긴 개발 장면에서는 마지막 사건이 끝난 뒤 침묵이나 빵 먹는 동작이 이어졌다. 풍부한 등대 프로필 이관 표본에서 두 인물은 같은 말의 박자를 골랐다. 회상도 낱말 중심이라 “아까 그거”처럼 대상이 생략된 발언에서는 가져올 대사를 찾기 어렵다. 이 결과는 두 명의 화자만 등장하는 제한된 장면과 한 모델에서 얻었다.

```sh
npm run character:eval -- --split development --turns 12
npm run character:eval -- --split holdout --turns 6 --repetitions 2 --live
npm run character:eval -- --split blank --live
npm run character:eval -- --split migration --live
```

`--live`가 있는 명령은 실제 API를 사용한다. 각 실행의 계획과 원문은 `.cache/character-performance/`에 저장된다. 고정 입력·모델로 다시 실행해도 공급자의 생성 결과는 달라질 수 있다.
