# 대화 연속성 검토 · 2026-11-07

## 결정

새 실행의 기본 반응 지침을 `npc-dialogue/3`에서 **`npc-dialogue/5`**로 바꾼다. `/4`는 비교 기록으로 남기고 기본값으로 채택하지 않는다. 기존 실행·세션을 소급 변경하지 않는다.

이번 변경은 이미 받아들인 약속과 같은 몸짓을 반복하는 문제를 줄인다. 그 과정에서 발견한 “말이 끝나면 실제 행동도 멈춤”을 v5에서 보완했다. 모든 인물·장면의 자연스러움을 보증하는 결과는 아니다. 특히 친구끼리의 장난스러운 대꾸가 줄어드는 취향 차이는 남는다.

v4는 덮어쓰지 않았다. 정확한 정책 본문·원인·계보는 `src/core/dialogue-policies.ts`와 `world-policies.ts`, 고정 해시는 테스트에 있다. v4/v5 비교 당시 composer는 대부분 `npc-lab/7`; 평가 입력 보강이 들어 있던 작업 트리였다. 평가 호출은 꺼 두었다. 이후 이 보강을 `npc-lab/8`로 명명했고 NPC persona의 다른 부분은 바꾸지 않았다. 마지막 서월 비교는 `/8`에서 실행했다.

## 비교 조건과 증거

정책별 새 세션, 같은 입력·프로필·모델·추론 수준을 사용했다. 고정 입력은 호출 순서와 A/B 슬롯을 교차 배치했다. 여러 차례 대화는 실제 응답에 따라 갈라지므로 후속 입력까지 동일하다는 뜻은 아니다. 연속 대화의 같은 장면 안에서는 정책 순서가 고정돼 있으며 순서 효과를 완전히 제거하지 못했다.

고정 입력의 참고 기준과 상대 비공개 기억은 NPC에게 전달하지 않는다. 원문을 읽은 주체는 프롬프트 작성 에이전트다. **사용자 평가나 독립 블라인드 평가가 아니다.** 침묵 횟수·짧은 문장·종료까지의 호출 수를 자연스러움 점수로 계산하지 않았다.

| 비교 | 실제 호출 | 조건 |
|---|---:|---|
| Codex v3/v4 고정 입력 | 80 | `gpt-6-sol / low`; 개발 32, 전이 24, 기존 회귀 24 |
| Codex v3/v4 연속 대화 | 123 | 영화·충전기, 정책별 각 2회, 최대 18차례 |
| 기존 세계 코드 실패 확인 | 12 | 깨끗한 c20bca1의 세계 코드, Luna medium, 두 실행 모두 관찰 분류 오류로 일시정지 |
| API v3/v4 고정 입력 | 80 | `gpt-6.1-sol / low`; 개발 32, 전이 24, 기존 회귀 24 |
| API v3/v4 관찰 장면 | 72 | 세계 Luna medium, 정책별 18차례 1회 |
| API v5 고정 입력 비교 | 64 | v3와 회귀 24·전이 24; v4와 후속 행동 16 |
| API v3/v5 연속 대화 | 123 | 영화·충전기, 정책별 각 2회, 최대 18차례 |
| API v3/v5 관찰 장면 | 144 | 세계 Luna medium, 정책별 18차례 2회 |
| 서월 v3/v5 | 101 | 18차례씩, NPC Sol low / 진행자 Luna low / 세계 Luna medium |

합계 **799회**. 복구된 OpenAI 경로 584회, 로컬 가격표 추정 **$0.812291925**. Codex 경로 215회, API 단가 환산 $1.9873427이며 구독 청구액이 아니다. 모든 시도와 실패를 포함한 집계는 [manifest.json](manifest.json)에 있다. API 잔액 자체를 조회하지 않았고 실제 요청 성공으로 복구를 확인했다. 실패한 세계 실행은 성공 수에 넣지 않았다.

개발·전이 사례는 이 변경을 작성한 에이전트가 만들었다. 전이 세트는 v4 때 먼저 읽었으므로 **v5의 미공개 holdout이라고 주장하지 않는다.** 후속 행동 세트 역시 발견한 문제를 바탕으로 작성했다. v5에 대한 고정 입력 32쌍의 판정·근거는 [pair-reviews.json](pair-reviews.json)에 별도로 남긴다.

## 원문에서 확인한 변화

### 대화가 끝나도 아직 할 행동은 남는다

v4 영화 첫 실행은 코미디에 합의하고 간식을 가져왔지만 영화를 재생하지 않은 채 모두 조용해졌다. 그래서 종료 횟수가 줄었다는 이유로 채택하지 않았다. [실패 양상 원문](codex-v4-conversations/sofa_evening-npc-dialogue-4-1.md)

v5 영화 두 실행은 민아가 7번째 차례에 재생 버튼을 누르고, 간식을 먹은 뒤 새로운 내용 없이 “계속 본다”를 반복하지 않았다. 14번째 선택에서 대화 전용 종료 조건을 만족했다. 둘의 발언·취향 차이와 양보까지 없앤 것은 아니다. [1회](api-v5-conversations/sofa_evening-npc-dialogue-5-1.md), [2회](api-v5-conversations/sofa_evening-npc-dialogue-5-2.md)

v4 충전기 장면은 물건을 손에 들고 방으로 돌아간 뒤 실제 연결이 없었다. “충전기 찾기”라는 좁은 목표는 달성했지만 배터리가 부족하다는 일상 맥락의 후속 행동이 끊긴 사례다. [원문](api-v4-observed/charger_with_observation-npc-dialogue-4-1.md)

v5는 두 번 모두 13번째 차례에 충전기를 연결했고 세계 엔진이 충전 표시를 공개했다. 해당 모드는 조용해져도 자동 종료하지 않고 18차례 한도까지 실행했다. [1회](api-v5-observed/charger_with_observation-npc-dialogue-5-1.md), [2회](api-v5-observed/charger_with_observation-npc-dialogue-5-2.md)

후속 행동만 명확히 준 고정 사례에서는 **v4와 v5 모두 행동했다.** 이 시험만으로 v5가 더 좋다고 할 수 없으며, 여러 차례 대화에서 드러난 중단 사례가 채택 결정의 이유다. [16개 출력](api-v5-follow-through/samples.jsonl)

### 필요한 대답과 자발적 관심은 유지한다

v5는 라디오를 계속 듣는 두 표본에서 빈 선택을 냈다. 반면 새 라면 제안, 비로 바뀐 계획, 아직 화난 상대, 좋아하는 책의 감상 질문, 회사 합격 소식에서는 모두 실제 말을 했다. 이는 지시받은 질문에만 답하는 정책으로 제한하지 않았다는 좁은 증거다. [24개 출력](api-v5-transfer/samples.jsonl)

기존 12개 회귀 사례에서는 수리비를 모른다고 말하며 존댓말을 유지했고, 도자기 만드는 과정을 길게 설명했다. 다른 인물의 집주인·보증금 기억을 꺼내지 않았고 상대가 동의했다고 대신 서술하지 않았다. 전체적으로 두 정책 사이의 명확한 우열을 매기지 않았다. [24개 출력](api-v5-regression/samples.jsonl)

### 서월 인물의 말 선택

같은 `seowol-interaction/4` 프로필을 고정하고 공통 정책만 v3/v5로 비교했다. 새 공통 정책과 새 캐릭터 프로필의 효과를 합쳐 주장하지 않는다. 두 실행 모두 끝났고 v5는 다음처럼 사고를 축소한 말에 상대가 되묻는 흐름을 보였다.

> 도하: 그거 모서리 좀 찍혀서 감아 둔 거야. 들고 오다가 턱에 걸렸어.
>
> 소진: 네가 걸린 거야, 앰프가 떨어진 거야?
>
> 도하: 앰프가. 턱에서 한 번 떨어졌어. 막 굴러간 건 아니고.

후반에는 복만이 확인하려는 일과 소진의 식사가 충돌했다. 자동 화해나 모두가 함께 수리 계획을 정리하는 방식으로 마무리하지 않았다. v3도 자연스러운 빈정거림을 보였으므로 **서월 단일 비교에서 v5의 전반적 우월성을 선언하지 않는다.** [v3 원문](seowol-v3/run-1.md), [v5 원문](seowol-v5/run-1.md)

## 세계 엔진과 남은 제한

기존 커밋의 세계 지침·스키마를 사용한 별도 실행은 `observation`에 NPC ID를 넣어 두 번 모두 중단됐다. 기존 미커밋 보강은 바로 이 유형 경계와 조기 마감 완료를 다루고 있었다. 이 변경을 검토해 `npc-world/2`로 보존했다. 유효성 검사를 완화하거나 잘못된 결과를 자동 승인하지 않았다. [실패 기록](world-v1-failure/result.json)

실패 확인은 Codex 경로, 보강 뒤 검증은 OpenAI 경로다. NPC 모델도 달라졌으므로 오류 감소 전부를 세계 프롬프트 하나의 인과 효과로 수치화할 수 없다. 보강 후 세계 호출의 실제 성공과 기존 경계 테스트를 근거로 편입했다.

- 세계 엔진이 서월에서 “밥을 한 숟갈 먹었다”, 충전기 장면에서 단순 이동·물건 내려놓기를 다시 중계했다. 새 관찰만 공개하려는 지침이 아직 일관되게 지켜지지 않는다.
- 세계를 끈 충전기 장면은 발견 결과를 알려 줄 주체가 없다. v5가 조용히 끝나더라도 물건 찾기 성공으로 세지 않았다. 상태 변화가 중요한 실험에는 관찰이 있는 비교를 함께 사용했다.
- v3 영화 표본의 “찍는 것도 실력” 같은 가벼운 대꾸도 자연스러울 수 있다. v5가 더 빨리 조용해지는 것은 사용자 취향에 따라 단점이다. 이전 정책은 계속 선택 가능하다.
- 일상 몇 장면과 서월 한 장면, 주로 `initial_only`/모아 전달 조건이다. 다른 세계 36명 전체, 장기 기억, 분산 공간, 모델 간 품질은 이번 실제 비교로 검증하지 않았다.
- 사람 같은 반응의 보편적 성공률을 계산하지 않는다. 다음 변경은 세계의 중복 중계, 과도한 침묵과 자발적 잡담의 균형, 인물별 장기 표본을 우선한다.

## 코드 검증과 추적

전체 테스트 167/167, 타입 검사, 서버·웹 빌드, 캐릭터 팩 검증·모의 실행, 편집기 브라우저 검사를 수행했다. 최종 기본값 변경 후 관련 정책·세계·서월 테스트와 UI를 다시 확인했다. 구조·저장·격리 검증이며 자연스러움 점수로 환산하지 않는다.

호출마다 실제 세션 지침 SHA-256과 전송 응답 스키마 SHA-256을 기록한다. 세계 버전은 저장된 세션 지침을 동결된 본문과 대조해 결정한다. 예전 세션이 재개됐다는 이유로 새 세계 버전을 붙이지 않는다. 알 수 없는 본문은 `null`이다. 세계·진행자·출력 스키마도 자료 팩 호환 해시에 포함했다.

원본 API 이벤트·완전한 요청은 manifest의 로컬 `.cache` 경로에 남아 있다. 저장소에는 고정 입력의 응답 원문·실행 manifest, 대화 전문·설정, 세계 호출의 입력·출력·메타데이터를 보존했다. 대화 Markdown의 끝 빈 줄만 정리했으며 원본·보관본 해시를 따로 기록했다. 출력 문장을 다듬거나 실패를 삭제하지 않았다. 과거 서월 보고서는 당시 프롬프트와 결과를 유지한다.
