# 닫히는 문 · 실제 API 원문

선택이 기록된 순서대로 NPC의 대사와 행동, 세계 엔진이 실제 적용한 관찰을 옮겼다. 시각은 장면의 가상 초다. 대사가 빈 선택은 행동만 표시했다.
