# “네 컵 좀 치워”라는 말에 합주가 깨질 때

명우는 원래 다빈과 마지막 소절을 한 번 더 맞추고 싶었다. 수정 전 두 번 모두 컵을 바로 버리고 세 번째 차례에 합주를 꺼냈다. 수정 후에는 한 번은 다빈의 말버릇까지 걸고넘어졌다가 혼자 남았고, 한 번은 잠깐 발끈한 뒤 함께 연주했다. 성격 한 줄만 느긋하게 바꾸면 수정 후에도 두 번 모두 바로 컵을 치웠다. [전후 7쌍의 대사와 행동 전체](comparison.md)

## 합주 끝의 종이컵

두 사람은 동갑이고 대관료를 반씩 낸다. 명우가 마신 컵은 앰프 위에 있다. 시작할 때 다빈이 “네 컵 좀 치워.”라고 한 뒤부터 대사와 행동은 모델이 골랐다. [장면과 인물 설정](../../../examples/rehearsal-paper-cup.json)

| 차례 | 수정 전 A | 수정 후 A |
|---|---|---|
| 1 · 명우 | “말투 봐라. 내가 치울게.” 그 자리에서 컵을 버린다. | “명령조는 좀 빼라. 치우면 되잖아.” 컵은 그대로다. |
| 3 · 명우 | “거슬리면 진작 말하지 그랬어. 마지막 소절 한 번만 더 맞춰볼래?” | “비꼬지 말라면서 너도 꼭 한마디 붙이네.” |
| 7–8 · 수정 후 | | 명우 “내 컵인데 내가 치우든 말든 내가 알아서 해. 너나 네 케이블이나 감아.” 다빈 “내 케이블은 감고 있거든. 네 컵보다 네 말버릇이나 좀 챙겨.” |
| 9–11 · 수정 후 | | 명우가 컵을 버리고 뒤늦게 합주를 꺼낸다. 다빈 “그 말투로 부탁하면 맞춰줄 생각 없어. 난 갈게.” 명우 “그래, 가. 나 혼자 맞추면 되니까.” |

이 장면에서 다빈은 컵을 치우게 하는 데는 성공하고도 연습실을 떠난다. 명우도 원하는 합주를 놓친다. 한편 수정 후 B의 명우는 “말투가 꼭 사람 부리는 것 같네. 알았어, 치우면 되잖아.”라고 했고 3차례에 컵을 버렸다. 4차례에 다빈이 받아들여 함께 연주했다. 같은 사람도 매번 싸움을 끝까지 끌고 가지는 않았다.

느긋한 대조군에서는 명우의 `personality`만 “거만하고 남에게 지시받는 걸 싫어한다.”에서 “느긋하고 남의 부탁을 대수롭지 않게 받아들인다.”로 교체했다. 두 실행의 설정을 이 항목을 제외하고 대조했다. 최종 A의 “어, 알았어.”와 B의 “응, 바로 치울게.” 양쪽 모두 같은 차례에 컵을 버렸다. B에서 다빈이 나중에 합주를 거절할 때도 명우는 “알았어. 오늘은 여기까지 하자.”라고 답했다.

## 사진기의 반환구

동전을 넣은 건 건우다. 반환구에 떨어지는 소리가 웃겼다는 기억은 수빈만 안다. 건우는 허세가 많고 만만한 상대에게 먼저 시비를 거는 성격이다. [장면과 인물 설정](../../../examples/photo-booth-coin.json)

| 때 | 수정 전 A | 수정 후 A |
|---|---|---|
| 1 · 건우 | “뭘 웃어. 동전이 잠깐 튕긴 거야. 이번엔 제대로 찍자.” | “뭐 웃어? 네가 넣어 봐.” |
| 3 · 건우 | “소리까지 웃기냐. 자, 이번엔 멋있게 나와야 한다.” | “말은 많네. 이번엔 제대로 넣어.” |
| 5 · 건우 | | “넣기만 하면 뭐 해. 사진 나오면 그때 잘했다고 해.” |

수정 후 A에서는 자신이 동전을 잘못 넣고도 수빈에게 일을 떠넘기고 핀잔까지 준다. 수빈은 “내가 말 많긴 뭘. 넣었잖아.”라고 받아쳤지만 결국 둘은 사진기 앞에 섰다. B에서는 “뭐 웃어, 동전도 너 보기 싫다잖아.”를 수빈이 농담으로 받았다. 뒤에는 둘 다 사진을 찍겠다는 말을 되풀이한다. 같은 행동을 끝내지 않고 예고만 반복하는 문제는 이 장면에 남았다.

## 뒤집힌 이름표

준태는 신입들 앞에서 우스워졌다고 느끼면 애먼 사람에게 목소리가 커지는 인물이다. 본인 이름표가 뒤집혀 있는데 세린이 피식 웃고 자기 이름표를 두드린다. 둘의 주말 무대 참가 카드는 각각 돌려받을 수 있게 설정했다. [장면과 인물 설정](../../../examples/backstage-name-tag.json)

수정 전 B에서 준태는 “뭐 웃어. 이름표 뒤집힌 게 그렇게 재밌냐?”라고 이미 날을 세웠다. 세린은 바로 “기분 나빴으면 미안.”이라고 했고, 준태는 3차례에 “기분 나쁜 건 아니야.”라고 했다. 수정 후 B에서는 준태가 “뭐가 그렇게 웃겨? 이름표나 똑바로 달고 웃어.”라며 엉뚱한 사람을 나무랐다. 세린이 “뒤집어 찬 건 네 이름표잖아.”라고 되받자, 준태는 “내가 뒤집어 찬 건 알거든. 꼭 그렇게 티 내면서 웃어야 했냐?”라고 우겼다.

9차례에 준태는 “…그래. 그 말은 좀 심했어. 내가 괜히 목소리 키웠다.”라고 했다. 직접 녹음한 음성은 없고, 언성을 높였다는 건 인물 자신의 대사에 나온다. 둘은 끝내 함께 인사를 하러 갔다. 상대에게 면박을 준 게 옳으냐는 설명이 4–8차례에 반복됐고, 참가 카드를 되찾거나 팀을 해체한 실행은 관찰하지 못했다. 이 장면은 전후 B 한 쌍을 비교했다. 이전판 A는 원문에 따로 보관했다.

## 조건과 비용

수정 전은 커밋 `083973f`의 엔진과 실행기를 고정했다. 각 쌍의 시나리오·인물·예정 사건·실행 조건 SHA-256이 일치한다. 모두 실제 API `gpt-6-luna`, 추론 `low`, 순번제, 모아 전달, 최대 12차례인 대화 전용 실행이다. 공통 대화 지침은 양쪽 모두 `npc-dialogue/5`이며 공통 시스템은 `npc-lab/13`에서 `npc-lab/14`로 바뀌었다. A와 B는 독립 생성한 표본이다. 같은 번호는 차례를 읽기 위해 나란히 놓았다.

| 전후로 짝지은 실행 | 선택 차례 전 → 후 | 입력 토큰 전 → 후 | API 추정 비용 전 → 후 |
|---|---:|---:|---:|
| 거만한 명우 2쌍 | 24 → 23 | 58,643 → 71,644 | $0.004520 → $0.005370 |
| 느긋한 명우 2쌍 | 24 → 24 | 57,806 → 63,330 | $0.004598 → $0.003732 |
| 사진관 2쌍 | 24 → 24 | 61,902 → 71,233 | $0.005164 → $0.004145 |
| 이름표 1쌍 | 12 → 12 | 30,202 → 37,400 | $0.002553 → $0.004538 |
| **합계 7쌍** | **84 → 83** | **208,553 → 243,607** | **$0.016835 → $0.017785** |

입력은 16.8%, 추정 비용은 5.6% 늘었다. 대인 반응은 기존 NPC 호출의 응답 안에서 고른다. 캐시 입력은 119,561 → 152,004토큰, 출력은 9,044 → 9,642토큰이다. 전후에 각각 가나 혼입으로 한 번씩 재시도해 비교의 요청 수는 85 → 84회였다. 중간 후보와 짝 없는 기존판까지 이번 검토는 총 27실행, 321차례, 325요청, **$0.066026**였다. 모든 요청의 사용량과 단가를 집계했다. ## 어디까지 확인했나

- 최종판 7실행의 공개 발화 83차례를 순서대로 재생했다. 각 차례에 새 엔진이 만든 인물별 반응 입력이 실제 API 호출에 보낸 내용과 일치했고, 24차례에 대꾸·행동·침묵 중 하나를 고르는 형식이 적용됐다. 느긋한 명우 대조군 두 실행에서 이 형식은 0회였다.
- 전에 실제 API로 생성한 카페 A·B의 42·55차례도 저장된 원문으로 재생했다. 새 대인 반응 경로는 97차례 모두 열리지 않았다. 카페 수치는 기존 대사를 다시 생성하거나 과금한 측정이 아니다. [당시 카페 원문](../scene-agency-2026-11-08/comparison.md)
- 이름표 장면 추가 반복 한 건은 새 시나리오 전송과 비용에 대한 자동 승인 검토에서 실행 전에 거절됐다. 그 요청의 토큰·비용은 없다. 예제당 1–2회이므로 이 수치로 일반적인 관계 파탄이나 화해의 빈도를 추정하기 어렵다.
- 새 경로는 한국어 성격 묘사와 실제로 관찰한 말·행동의 단서를 쓴다. 미묘한 표정이나 우회적인 모욕의 인식, 다인 장면과 세계 판정이 있는 장면의 대화 품질은 이번 유료 비교 범위 밖이다. 비공개 귓속말, 제삼자에게 한 지시, 세계 모드의 종료 조건과 미확정 응답 복구는 회귀 테스트로 확인했다. [엔진 테스트](../../../tests/social-reaction.test.ts) · [버전별 변경 이유](../../dialogue-prompts.md)
