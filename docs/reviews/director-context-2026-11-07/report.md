# 질문 상대와 공개 시작 장면 · 2026-11-07

**진행자 `director/4`를 적용한다.** 다음 화자를 고를 때 최근 발언에서 생략된 당사자를 알 수 있도록, 단일 공간의 공개 시작 장면을 전달한다. 기존 NPC `/5`와 서월 프로필 `/1`은 그대로다. 이 수정은 대화 연결의 입력 누락을 해결하며 인물별 말투가 모두 개선됐다는 뜻은 아니다.

## 원인과 변경

[프로필 대조군 대화](../profile-voice-2026-11-07/profile1-maintenance/transcript.md) #1에서 유진은 “표시한 두 항목이 헷갈리는 거예요? 좀 볼게요”라고 물었다. 고지서는 연우가 가져왔고 하린은 동행이지만, /3 진행자 입력에는 이름과 최근 발언만 있었다. 진행자는 하린을 당사자로 잘못 추정했다. 유진과 하린이 #2~#5를 무언·무동작으로 넘긴 뒤, 장기 배제 방지 규칙으로 #6에 연우가 선택되어야 답이 이어졌다.

/4는 `initialScene`으로 `scenario.situation`만 전달한다. 이는 이미 단일 공간의 NPC 프롬프트에 제공된 시작 장면이다. 개인 프로필·세계 판정용 비공개 지침은 넣지 않는다. 분산 공간 진행자에는 전역 시작 장면을 전달하지 않아 다른 장소의 정보가 새로 들어가지 않는다.

새 지침은 시작 장면을 생략된 당사자 파악에 사용하되 **이후 실제 대화·행동을 우선**하도록 명시한다. 허용 화자 enum, 장기 배제 방지, 연속 화자 제외, 새 진행자 세션, 미확정 호출 복구는 유지한다. 시작 장면은 JSON 직렬화 기준 최대 2,400자, 전체 입력은 기존 16,000자 한도를 지킨다. 긴 장면이 잘리면 메타데이터에 남으며 잘린 정보로 상대를 항상 맞힐 수 있다고 보장하지 않는다.

기존 /3 지침은 `legacyDirectorInstructions`에 바이트 그대로 보존한다. /4 지침 SHA-256은 `9075d7ea75d0d4f386273e47a73cb304a1e478205f13c687812c784125021971`이다. 호출별 `directorContext.version`, 실제 세션 지침·입력·스키마 해시를 기록한다. 이미 완료된 결정은 재사용하고, 새로 만드는 결정은 현재 버전을 사용한다. 과거 호출을 /4로 소급 표기하지 않는다.

## 실제 API 비교

공개 시작 장면을 넣기 전후의 고정 입력 6개를 각각 5회, 새 세션의 `gpt-6-luna / low`로 비교했다. A/B 호출 순서를 교차했다. 세 개는 실제 실패 시점, 세 개는 수정 문구를 동결한 뒤 확인한 별도 상황이다. 기대 화자는 사례 생성 시 고정했으며 자연스러움 점수가 아니다.

| 사례 | /3 기대 선택 | /4 기대 선택 |
|---|---:|---:|
| 고지서 첫 질문 | 0/5 | 5/5 |
| 동행이 한 차례 침묵한 뒤 | 0/5 | 5/5 |
| 두 사람이 침묵한 뒤 | 2/5 | 5/5 |
| 새 상황: 소포 주인에게 생략된 질문 | 0/5 | 5/5 |
| 새 상황: 이전 용건 후 다른 사람에게 명시적 질문 | 5/5 | 5/5 |
| 새 상황: 지목 상대가 허용 후보에 없음 | 5/5 | 5/5 |

당사자 정보가 필요한 네 상황에서는 **2/20 → 20/20**, 후속 명시 질문·허용 후보 회귀에서는 양쪽 모두 10/10이었다. /3에는 당사자를 알아낼 정보가 없었으므로 이는 모델 능력 비교가 아니라 입력 누락 수정의 근거다. 유효 JSON·허용 후보 준수는 60/60이었다. [실제 요청](fixed/requests.jsonl)과 [출력](fixed/samples.jsonl)을 보존했다. `instructions.txt`는 대조군 /3 지침이며, 각 요청에 /3·/4 전체 실효 지침이 따로 있다.

기존 프로필 /1·NPC /5·세계 /6·동일 모델을 유지한 고지서 대화도 18차례씩 2회 실행했다. 두 실행 모두 **#2에서 연우가 바로 답했고 질문 뒤 잘못 선택된 인물들의 침묵 반복이 없었다.** 기존 대조군은 연우의 첫 답이 #6이었다. [반복 1](conversation/run-1/transcript.md), [반복 2](conversation/run-2/transcript.md)에 전체 대화를 남겼다.

첫 반복에서는 하린이 청음회 계획을 꺼냈고, 두 번째에서는 연우가 도움의 비용을 되물었다. 기존 성격이 드러날 발언 기회가 생긴 사례지만, 두 경로만으로 말투 전반의 향상을 주장하지 않는다. 두 번째 #6의 하린 침묵은 장기 배제 방지로 받은 선택 기회다. 모든 침묵을 오류로 없애지 않았다.

| 실행 | 호출 | 추정 USD |
|---|---:|---:|
| 고정 입력 6개 × 2버전 × 5반복 | 60 | 0.005128 |
| 이어지는 대화 18차례 × 2회 | 106 | 0.125101 |
| 합계 | **166** | **0.130229** |

모두 완료했고 미산정 호출은 없다. API 사용량과 가격표 `33fd7a5a40495c1a`에 따른 추정이며 실제 청구서·잔액이 아니다. 앞선 대조군 대화는 기존 [프로필 검토](../profile-voice-2026-11-07/report.md)의 385회에 포함되므로 이 표에 중복 합산하지 않았다. [매니페스트](manifest.json)에 해시와 원본 실행 위치가 있다.

## 재현과 검증

```powershell
# --live를 빼면 검증과 계획만 출력한다.
node --env-file-if-exists=.env --import tsx scripts/director-eval.ts --comparison context --cases evals/director/context.json --repetitions 5 --max-calls 60 --max-usd 1 --live

# 운영 프로필은 그대로이며 별도 저장소에서 두 번 실행한다.
node --env-file-if-exists=.env --import tsx scripts/seowol-live.ts --spec assets/seowol/experiments/maintenance-talk.json --label director4-maintenance --model gpt-6.1-sol --policy npc-dialogue/5 --world-policy npc-world/6 --turns 18 --repetitions 2 --max-calls 120 --max-usd 1 --live
```

타입 검사·빌드·전체 테스트 **180/180 통과**. 입력 한도, 제어 문자·이모지, 예전 지침 동결, 개인 기억·세계 비밀 제외, 분산 공간의 전역 장면 제외, 실패 재시도·미확정 결정 재개와 120차례 진행을 포함한다. 실제 API 검토는 이 보고서의 별도 166회이며 모의 테스트를 대화 품질 표본으로 세지 않는다.

보관 자료 14개 해시·크기와 고정 입력 요청 60개의 현재 코드 재현을 확인했다. 연속 대화 호출 106개의 지침 해시·/4 기록, 대조군과 후보의 NPC·세계 설정 일치, 보고서 관련 로컬 링크 43개를 검증했다. 공개 파일 검사도 786개·58.36 MiB에서 문제 없이 통과했다. 이는 현재 파일의 패턴 검사이며 Git 전체 이력이나 이미지 메타데이터 감사는 아니다.
