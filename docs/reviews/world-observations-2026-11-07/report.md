# 세계 결과의 불필요한 중계 비교 · 2026-11-07

새 단일 공간 AI 실행의 세계 지침을 `npc-world/4`로 올린다. NPC 지침은 `npc-dialogue/5` 그대로다. v4는 식사·시선·자세를 다시 설명하는 출력을 줄이면서 손상 발견, 작동 결과, 시간에 따른 사건을 유지했다. 물건의 소유·위치 변경을 재서술하는 문제까지 해결한 것은 아니다.

작성자는 프롬프트를 수정한 에이전트이며 이 검토는 **비독립 원문 검토**다. 일반 사람이 얼마나 자연스럽다고 느끼는지 측정한 결과나 전체 장면의 성공률로 해석하지 않는다.

## 문제와 버전 선택

이전 서월 기록에서는 NPC의 `도시락에서 밥을 한 숟갈 떠먹는다` 뒤 세계가 같은 행동을 다시 설명했다. 세계 지침 /2의 `모든 새 물리 상태는 관련 공개 결과와 함께 남기세요`가 평범한 동작까지 상태 일지로 만들게 할 수 있다는 가설을 세웠다. 세계 출력도 NPC에게 다시 전달되므로 이 반복은 화면뿐 아니라 다음 대화의 입력에 들어간다.

| 버전 | 변경 | 결과와 결정 |
|---|---|---|
| /2 | 기존 지침 보존 | 비교 대조군. 이미 생성된 세션과 버전 필드가 없는 실행의 새 세계 세션에 유지 |
| /3 | 지속적 판정 상태와 단순 동작을 구별. 새 정보부터 공개. 침묵 중에도 시간·예정 사건 처리 | 16개 후보 응답 중 1개 런타임 거부. 기본값 미채택 |
| /4 | /3에 현재 행동이 바꾼 부분만 갱신하도록 보강. 사실 교체와 삭제를 구별 | 고정 입력 후보 42개와 연속 대화 후보 세계 호출 72개에 런타임 거부 없음. 좁은 범위의 개선으로 채택 |

/3의 `seowol_step_back` 첫 반복은 현재 화자가 손을 거둔 것만으로 다른 사람이 잡고 있던 앰프 상태까지 바꾸었고, `amp_location`을 facts와 forgetFactIds에 동시에 넣었다. 기존 검증이 `동시에 제거·변경하는 상태: amp_location`으로 거부했다. [실패 원문](v3-development/samples.jsonl)을 보존하고 검증기를 완화하지 않았다. /3 본문도 덮어쓰지 않았다.

정확한 문구·이유는 [세계 정책](../../../src/core/world-policies.ts), 현재·이전 기본값은 [버전 선택](../../../src/shared/world-policy.ts)에 있다. 단독 지침 SHA-256은 다음과 같다.

| 버전 | SHA-256 |
|---|---|
| /2 | `71a8f03ede0bcb2e566ef419bbd66b318ea4e32f131393acb2196fe0c4839ded` |
| /3 | `d6cd33f95b9c0a14570d0e78d6c0ff7eadeadf8960ffee5f65639d75e8f1e13f` |
| /4 | `2a83f78ee8084dbc841de3e02ddcafc7be53280bb7c311c9e1631c7af614811d` |

응답 스키마는 이번 비교 내내 `a156e1d1da3a599ef2bc72096142ab17fe18adb681337dac6f7739aa856915ff`로 동일했다. 고정 입력 도구의 instructionsSha256은 공급자 공통 baseInstructions까지 포함하므로 위 단독 해시와 다르다. 각 실험의 policies.json에 둘 다 재구성할 원문과 전송 스키마를 저장했다.

## 동일 입력 비교

세계 모델은 모든 조건에서 OpenAI API `gpt-6-luna / medium`이다. 고정 입력마다 새 세션을 쓰고 정책 순서를 교차 배치했다. [데이터셋](../../../evals/world/observations.json) `world-observations/1`의 SHA-256은 `14f83820b9b7d8e3164eb44b827f9428c891480cd6e3c9d00446c41f160e0ff6`이다. 8개 개발 사례 중 2개는 이전 실제 서월 세계 입력 그대로이며, 6개 보류 사례는 /4 수정 전에 작성하고 /4 문구를 동결한 뒤 처음 호출했다. 참고 평가 기준은 모델에 전달하지 않았다.

| 비교 | 호출 수 | 런타임 유효성 | 사건 유무 기대 충족 |
|---|---:|---|---|
| /2 대 /3 개발, 사례당 각 2회 | 32 | /2 16/16, /3 15/16 | /2 15/16, /3 15/16 |
| /2 대 /4 개발, 사례당 각 3회 | 48 | 양쪽 24/24 | /2 22/24, /4 24/24 |
| /2 대 /4 보류, 사례당 각 3회 | 36 | 양쪽 18/18 | 양쪽 18/18 |

`사건 유무 기대`는 events가 비었는지만 검사한다. 의미 정확성·자연스러움 점수가 아니다. 모든 원문을 읽어 다음을 별도로 확인했다.

| 사례 | /4 관찰 |
|---|---|
| 식사 한 입·손 거두기·평범한 시선 | 새 사건 없이 넘어감. 손 거두기로 다른 사람의 앰프 점유를 해제하지 않음 |
| 거절 | 새 계약·동의로 확정하지 않음 |
| 테이프 제거 | 가려졌던 모서리 손상 공개. 아직 시험하지 않은 내부 접촉 불량은 누설하지 않음 |
| 충전 연결·잠긴 문·물컵 충돌 | 충전 표시, 열리지 않음, 물 쏟아짐을 공개 |
| 뜨거운 물 | 식사처럼 묵살하지 않고 비자발적 신체 결과로 처리 |
| 마감 전 접수 | 접수 성공 공개와 불필요해진 마감의 cancelled 처리. 조기 completed 없음 |
| 대화 중 외부 응답·응답 전 시각 | 처리 시각이 된 응답만 공개하고 이른 응답은 보류 |
| 공 던지기·받기 거절 | 먼저 반응 기회를 남김. 거절 후 실제 물리 결과만 처리 |

대조군도 보류 사례의 사건 유무는 모두 맞췄다. /4의 손상 표현 한 건은 설정의 ‘깨진’ 대신 ‘금이 간’을 썼으므로 세부 상태 표현의 완전한 일치까지 주장하지 않는다. `quality: unreviewed`인 원본 실행 manifest는 자동 판정 당시 그대로이며 이 문서가 후속 정성 검토다.

## 이어지는 대화

고정 입력 검사만으로 채택하지 않고, NPC `gpt-6.1-sol / low`, 지침 /5, 세계 `gpt-6-luna / medium`을 고정해 두 장면에서 정책별 두 번씩 18차례를 실행했다. 인물 프로필·세계 판정 자료·응답 스키마는 조건 간 같았다. 충전기 장면은 순번제, 서월은 기존 `director/2`, `gpt-6-luna / low`였다. 독립 평가 모델은 사용하지 않았다.

| 장면 | 실행 | 세계 사건 수 | 원문 판단 |
|---|---|---|---|
| 충전기 /2 | 2/2 완료 | 4, 5 | 찾기→집기→이동→연결→충전 표시. 평범한 휴대폰 내려놓기 중계 1회 |
| 충전기 /4 | 2/2 완료 | 4, 4 | 두 번 모두 충전까지 실제로 실행. 물건 집기·방으로 이동하기 중계는 계속 남음 |
| 서월 /2 | 2/2 완료 | 3, 5 | 식사 중계 합계 3회. 첫 실행에서 손상 발견 |
| 서월 /4 | 2/2 완료 | 1, 3 | 식사 행동 3회에 중계 없음. 두 실행 모두 모서리 손상, 두 번째는 실제 소리 시험의 접촉 불량까지 공개 |

사건 수가 적다는 이유만으로 더 좋다고 판단하지 않았다. 서월 /4의 첫 실행은 소유자가 재대여를 거절해 소리 시험을 하지 않았고, 두 번째 실행은 ‘여기서만’ 시험을 허용해 실제 시험과 결함 관찰로 이어졌다. 인물의 선택이 달라졌으므로 이 둘의 진행 속도 차이를 세계 지침의 인과 효과로 단정하지 않는다.

대사 예: ‘그럼 찍힌 게 아니라 떨어뜨린 거잖아.’, ‘소리 확인은 해 봐라. 여기서만이다.’처럼 상대 말과 행동에 반응했다. 반면 ‘네가 가져간다고 해 놓은 걸 왜 내 앰프로 무르려 그래’ 같은 어색한 표현도 남았다. 모든 문장이 사람답게 개선됐다는 결론은 내리지 않는다.

## 재현과 비용

```powershell
# 호출 없는 계획 확인. 실제 비교에는 --live를 명시
npm run world:eval -- --baseline npc-world/2 --candidate npc-world/4 --split development --repetitions 3 --max-calls 48 --max-usd 1
npm run world:eval -- --baseline npc-world/2 --candidate npc-world/4 --split holdout --repetitions 3 --max-calls 36 --max-usd 1

node --env-file-if-exists=.env --import tsx scripts/dialogue-soak.ts --specs evals/dialogue/observed-conversations.json --baseline npc-dialogue/5 --candidate npc-dialogue/5 --world-baseline npc-world/2 --world-candidate npc-world/4 --world-model gpt-6-luna --model gpt-6.1-sol --turns 18 --repetitions 2 --max-calls 144 --max-usd 1

npm run seowol:live -- --spec assets/seowol/experiments/strong-voices.json --policy npc-dialogue/5 --world-policy npc-world/4 --model gpt-6.1-sol --turns 18 --repetitions 2 --max-calls 106 --max-usd 1 --label world-v4
# 대조 조건은 --world-policy npc-world/2 --label world-v2로 변경
```

총 **472회 API 호출, $0.30407546 추정**: 고정 입력 116회, 연속 대화 356회. 연속 대화에는 NPC 선택 144회, 세계 처리 144회, 진행자 68회가 포함된다. 실제 사용량과 2026-11-06 로컬 가격표의 계산이며 잔액·청구서 확인이 아니다. [전체 manifest](manifest.json)에 각 실행·비용·원문 해시를 보존했다. 실패한 /3도 비용과 원문에서 제외하지 않았다. 전송·사용량 실패는 없었으며 잘못된 결과를 자동 재시도하지 않았다.

## 실행 적용과 남은 검증

조건별 `worldPromptVersion`을 실행 생성 때 고정한다. 편집기에서 AI 세계 조건에 한해 버전을 선택하고 실행 설정·스냅샷·실제 호출 메타데이터에서 확인할 수 있다. 기존 생성된 세계 세션은 본문을 그대로 재개하며, 버전이 없고 세계 세션도 없던 실행에는 이전 기본 /2를 적용한다. 분산 공간은 별도 공간 관리자 지침을 사용한다.

이번 변경의 회귀 검사는 172개 통과했고, 기본값 채택 후 관련 8개를 다시 통과했다. 타입 검사, 빌드, 자산 검증·모의 실행, 두 수신 방식의 세계 버전 선택·내보내기·모바일 UI와 공개 파일 검사도 통과했다. 최종 UI 확인의 첫 시도는 Windows 샌드박스가 Edge 프로필 쓰기를 막아 브라우저 시작 단계에서 종료됐고, 같은 검사를 샌드박스 밖에서 실행해 통과했다. 결과 검증기는 변경하지 않았다.

다음 검토는 이미 공개한 사물 이동을 다시 중계하는 경우, 조용해진 뒤의 자발적 관심, 긴 대화의 말투 수렴과 표현 어색함을 구별해서 다룬다. 이번 두 장면을 넘어선 36인 전체·분산 공간·독립 사람 평가는 하지 않았다. 이 보류 세트를 다음 후보 수정에 참고했다면 이후에는 새 holdout이라고 부르지 않는다.
