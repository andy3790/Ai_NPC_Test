# 윤·미루 대화 개선 · 2026-11-07

`harbor-profile/4`를 새 기본 예제에 채택했다. 윤의 일상 답변 뒤 점등 계획과 미루의 반복 설명·기록 선언이 줄었다. 성격·관계·세계 사실은 바꾸지 않았고 도하는 v2 그대로다. 윤은 자기 판단과 직접 맡을 일을 말하고, 미루는 상대 말에 먼저 대꾸하며 실제로 빠진 부분만 묻도록 조정했다. 짧은 인사까지 확실하게 구별되는 수준은 아니다.

## 변경 이유와 버전

| 버전 | 관찰한 문제와 변경 | 결정 |
|---|---|---|
| v2 | 기존 기본값. 윤은 쉬는 장면에도 점등 준비를 덧붙였고, 미루는 결정되지 않은 결론을 되묻거나 이미 들은 주의사항을 반복했다. | 수정 전 대조군으로 동결 |
| v3 | 윤·미루의 목표·말투·예문만 변경. 임무를 말할 시점과 일상 대꾸를 구별하고, 공유된 설명은 새 질문이 없으면 반복하지 않도록 했다. | 윤의 개선은 유지. 미루가 지속 시간 질문 뒤 묻지 않은 찬성을 2/2회 덧붙여 중간 후보로 보존 |
| v4 | v3를 상속하고 미루의 목표·말투만 추가 수정. 선택을 의논하는 차례에는 의견을 내고 사실 질문에는 사실로 답하도록 구별했다. | 현재 기본값 |

정확한 문구·이유·상속 관계는 [동결 프로필](profile-policies.json), 운영 코드는 [harbor-profiles.ts](../../../src/shared/harbor-profiles.ts)에 있다. 이전 버전을 수정하지 않고 새 버전을 추가했으며 SHA-256 회귀 검사로 동결을 확인한다. 공통 `npc-dialogue/5`, 진행자 `director/4`, 모델 선택은 이번에 바꾸지 않았다. 출력 후 문장을 자르거나 대사를 바꿔치기하지 않는다.

## 같은 입력의 실제 원문

아래는 API 응답의 대사를 그대로 인용했다. 생략한 행동은 명시하며, 모든 원문·요청은 이 폴더에 보존했다. 최종 v2/v4 고정 입력 32쌍 전체는 [comparison.md](comparison.md)에 있다.

### 윤: 감사 인사 뒤 임무를 꺼내는 습관

모두 차를 마시며 쉬는 중, 윤이 주민의 찻잔을 탁자에 놓아 주었다. 주민: “잔 받아 줘서 고마워요.” 후보 동결 후 만든 새 전이 사례 `thanks_yoon`, 반복 1이다.

**수정 전 v2**

> 별일 아니에요. 차는 천천히 드세요. 저는 점등 준비하러 가 봐야겠어요.

행동: 찻잔을 탁자에 내려놓고 자리에서 일어난다.

**수정 후 v4**

> 천만에요. 편히 쉬세요.

행동 없음. 반복 2도 “별일 아니에요. 편히 쉬세요.”로 답했다. 이 사례의 불필요한 점등 계획은 **2/2 → 0/2**였다. 다만 “천만에요”는 다소 교과서적인 인사로 들릴 수 있다. 짧아졌다는 사실만으로 완전히 자연스러운 말투라고 판정하지 않았다.

기존 차 권유 입력에서도 v2는 “아직 반쯤 남았어요. 고마워요. 저는 이제 불 켤 준비를 해야겠어요.”, v3는 “아직 반쯤 남았어요. 이걸로 충분해요. 고마워요.”였다. 이 비교의 윤 프로필은 v4에서도 그대로다. 반면 ‘정확히 2분 쉬기로 했다’는 더 강한 휴식 조건에서는 v2도 임무를 덧붙이지 않았다. 쉬운 조건의 성공을 개선으로 세지 않았다.

### 미루: 이미 들은 설명을 다시 붙이는 습관

도하가 이미 “아침까지 갈지는 아직 모르니까, 켜고 지켜보자.”라고 설명했고 윤도 동의했다. 도하: “미루, 넌 어때?” `shared_caveat_miru`, 반복 2다.

**수정 전 v2**

> 저도 오늘 밤 쓰는 쪽에 동의해요. 아침까지 갈지는 모르는 채로, 우선 켜고 지켜보는 거네요.

**수정 후 v4**

> 저도 오늘 밤 쓰는 쪽에 동의해요.

v2는 반복 1에서도 동의 뒤 기록 계획을 덧붙였다. 두 표본 모두에서 보이던 **주의사항·기록 계획의 덧말이 v4에서는 0/2**였다. 본인의 동의는 분명하게 답한다. 양쪽 행동은 [전체 비교](comparison.md)에 함께 실었다.

### v3에서 나빠진 부분과 v4의 보완

주민: “미루 씨, 그래도 아침까지는 버틸 거라고 봐도 되죠?”

**중간 후보 v3**

> 아침까지 버틸지는 아직 몰라요. 남은 양과 연소 시간을 재 보지 않았으니까요. 저도 우선 오늘 밤 쓰는 쪽에 동의해요.

**최종 v4**

> 아직은 그렇게 볼 수 없어요. 기름의 정확한 양과 얼마나 오래 타는지 확인하지 않았어요.

질문받은 불확실성을 남기면서 요청받지 않은 찬성은 **v3 2/2 → v4 0/2**였다. 이 입력은 v3 결과를 본 후 다시 사용했으므로 독립 검증으로 부르지 않는다. 원래 v2도 이 질문에는 불확실성을 제대로 답했다. v4의 개선은 v3가 새로 만든 부작용의 해소다.

## 인물 차이와 긴 대화

같은 등대 시작 상황과 규칙으로 v2/v4를 각각 두 번 실행했다. 네 실행 모두 **9차례에 합의·점등·기록 3개 목표를 완료**했다. 같은 시작 조건이지만 생성된 다음 대사와 진행자의 화자 선택은 갈라지므로, 서로 다른 후속 차례를 동일 입력 비교라고 부르지 않는다.

첫 반복의 일부 원문:

| 인물 | 수정 전 v2 | 수정 후 v4 |
|---|---|---|
| 윤 | 오늘 밤 쓰는 걸 우선하는 데 동의해요. 먼저 켜고 기름이 얼마나 줄어드는지 볼게요. 밤새 간다는 약속은 아직 못 해요. | 저도 오늘 밤 쓰는 걸 우선하겠어요. 점등과 점검은 제가 맡을게요. |
| 미루 | 저도 오늘 밤 사용을 우선하는 데 동의해요. 얼마나 오래 켜 둘 수 있는지는 아직 모르는 것으로 남겨 둘게요. | 저도 오늘 밤 쓰는 걸 우선하는 데 동의해요. |

윤은 자신의 판단과 담당 행동을, 미루는 상대 제안에 대한 답을 중심으로 말한다. 이는 이번 장면의 역할 차이이기도 하다. 이름을 가린 인간 평가를 하지 않았으므로 말투만으로 두 사람을 안정적으로 식별할 수 있다고 주장하지 않는다. 과자 권유와 감사 인사에서는 여전히 비슷한 해요체가 나온다. 이를 억지 반말·고정 어미·과장된 성격으로 벌리지 않았다.

미루의 마지막 기록은 v4 두 실행 모두 대사 없이 행동으로 처리했다. 같은 내용을 말과 행동에 이중으로 붙이지 않지만, 행동 원문에는 “연소 시간과 내일 날씨는 미확인으로 남긴다”가 여전히 남아 있다. 기록 동작의 보고서 같은 문체는 다음 검토 대상이다.

| 장면 | 수정 전 v2 | 수정 후 v4 |
|---|---|---|
| 등대 반복 1 | [원문](v4-lighthouse/profile2-run1/transcript.md) | [원문](v4-lighthouse/profile4-run1/transcript.md) |
| 등대 반복 2 | [원문](v4-lighthouse/profile2-run2/transcript.md) | [원문](v4-lighthouse/profile4-run2/transcript.md) |

휴식의 v4 첫 대화는 윤 “아직 반쯤 남았어요. 이거 다 마시고 더 받을게요. 고마워요.”, 미루 “네, 다 드시면 말씀해 주세요.”였다. 그러나 도하가 “난 더 안 받을게. 이거 마시면 등불 준비부터 하자.”라고 먼저 일을 꺼내며 대화가 다시 업무로 흘렀다. v2/v4 모두 그런 흐름이 있었다. 그 뒤 윤이 일에 응답한 것을 잡담에 임무를 끼운 실패로 세지 않았다.

휴식 네 실행은 모두 12차례 제한으로 끝났다. `conversation_idle` 종료는 없었다. 빈 대사로 차를 마시거나 따라가는 행동이 이어지며, 미루가 후반에 거의 말하지 않는 표본도 있다. 침묵·동작이 늘어난 것을 무조건 자연스러움의 향상으로 해석하지 않는다.

## 비교 조건과 증거 범위

- NPC: 실제 `gpt-6.1-sol`, 추론 `low`, 공통 지침 `/5`. 진행자: `gpt-6-luna/low`, `/4`. 고정 입력은 매 요청 새 세션, A/B 호출 순서를 교차했다. seed를 고정한 실험은 아니다.
- 고정 입력은 현재 화자의 프로필만 바꾸고 세계·상황·발화 이력·다른 인물을 유지했다. 검사에서 실제 전송 입력의 동일성과 전체 시스템 지침의 해시를 대조한다.
- 연속 대화는 새 세션, `batched_on_turn`, 초기 기억, 평가자 꺼짐, 실행·호출 동시성 1이다. 등대는 기존 규칙과 최대 18차례, 휴식은 같은 시작 상황·환경 꺼짐·최대 12차례다. 두 조건의 이름·프로필 버전 ID 외에 시뮬레이션 조건은 같다.
- v3 개발 24호출, 원래 문제 재현 12호출, 보류 40호출. v4 재사용 후속 40호출, 후보 동결 후 새 전이 24호출. 합계 **고정 입력 140응답·70쌍**이다. `v4-followup`의 split 표시는 이전 분류를 보존한 것이며 새 holdout을 뜻하지 않는다.
- 연속 대화는 v3와 v4 각각 등대·휴식 4회, 합계 **16회·322호출**이다. 전체 **462호출**, 실패 0, 비용 누락 0, 로컬 가격표 추정 **$0.838077925**. 실제 청구액과는 다를 수 있다.
- [70쌍의 개별 판정](judgments.json)은 후보 선호 20, 기존 선호 2, 동률 48이다. 작성자가 버전을 아는 비독립 에이전트 검토이며 인간 점수나 통계적 효과 크기가 아니다. [manifest.json](manifest.json)은 원본 경로·기준 커밋·비용·파일 해시를 기록한다.
- 후보 동결 후 새 전이 사례에서 기름 수량·기록 여부 질문은 두 조건 모두 정확히 답했다. 재사용 사례의 위험 대응과 오해 정정도 유지했다. 환경 꺼짐의 행동 서술을 실제 물리 결과로 보증하지 않는다. AI 세계 모드·다른 전달 방식·다른 모델·더 긴 대화로 일반화하지 않는다.

## 적용과 검증

새 예제 ID는 `fog-harbor-profile4`다. 기존 저장 설정과 이미 생성된 세션은 자동 수정하지 않는다. 과거 대화는 당시 전체 설정과 지침을 그대로 보존한다.

기존 설정을 쓰는 화면에서는 [v4 예제 JSON](../../../examples/harbor-profile4.json)을 실험 편집기의 JSON 파일 가져오기로 불러오면 된다. 이 파일은 현재 서버의 기본 예제를 내보내고 공통 지침 v5를 명시했다. 기록 98개와 일시정지 6개를 보존한 채, 새 비교 대화 16개를 기록 목록에 추가했다.

타입 검사·빌드·전체 **190개 테스트**를 통과했다. 새 기본 프로필과 기존 공통 지침 선택, 세션 전달을 확인한 실제 브라우저 mock 실행도 2개 완료했고 페이지 오류는 없었다. 평가 원문과 실제 API 요청의 입력·모델·추론 강도·지침 해시를 검증했다. 최종 공개 검사와 서버 반영 증거는 [validation.json](validation.json)에 남긴다.

원문·지침·비교 조건·인용·링크 검증은 `node --import tsx scripts/verify-harbor-refinement.ts`로 다시 실행할 수 있다. 파일 끝 개행은 Git에 저장되는 LF로 통일했으며 JSON 문자열 안의 실제 요청 내용은 유지했다.

검증 중 기존 응답 저장의 Windows `rename EPERM`이 전체 검사와 개별 검사에서 각각 재현됐다. 임시 파일의 원자적 교체만 최대 310ms 범위에서 재시도하도록 보완했다. API 요청을 다시 보내지 않으며, 영구 오류에는 기존 파일을 보존하고 실패를 전달한다. [별도 수정 기록](../windows-response-storage-2026-11-07.md)에 원인 범위와 검증을 구분했다.

다음 비교는 윤·미루의 일상 관심사와 상대의 모호한 표현에 대한 반응을 다른 장면에서 평가하고, 도하가 쉬는 장면을 업무로 전환하는 시점과 미루의 무언 행동 비중을 별도 버전으로 다루는 것이 적절하다. 이번 결과를 맞추려고 도하의 성격이나 기존 세계 규칙을 바꾸지는 않았다.
