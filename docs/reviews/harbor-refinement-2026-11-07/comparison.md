# 동일 입력의 실제 대사 비교

v2 대 최종 v4의 32쌍을 빠짐없이 표시한다. 대사와 행동은 응답 JSON에서 그대로 옮겼다. `v4-followup`은 재사용 사례, `v4-transfer`는 v4 동결 후 만든 새 사례다. 두 조건의 공개 입력은 같다. 평가자의 주관적인 선호는 인간 평가 점수가 아니다.
