# Luna API 대화 전후 원문

왼쪽은 기존판, 오른쪽은 최종판이다. 같은 번호는 각 실행의 NPC 선택 순서를 뜻한다. 화자와 시각은 각 실행에서 실제로 기록된 값이다. 현장 행에는 다음 선택 전에 일어난 세계 판정과 시간 경과를 실었다. 모델 초안이 조정된 차례에는 원래 문장도 표시했다. [실행 조건과 판독](report.md) · [수신 범위가 포함된 구조화 원문](transcript.jsonl) · [비용과 버전](usage.json)
