## 같은 조건의 API 실행

기존판은 `09878cd`의 `npc-lab/16`, 최종판은 `npc-lab/17`이다. 관측기지의 세계 판정에는 `witness-memory/3`, 물리 판정이 없는 과수원의 대화에는 `witness-memory/2`가 적용된다. 관측기지는 같은 4인·3개 장소·`spatial-events` 시나리오로 128차례, 과수원은 같은 `orchard-a` · `initial`로 48차례씩 실행하도록 설정했다. NPC는 Luna low, 관측기지의 세계 계획·판정은 Luna medium, 상황 생성은 Luna low다. 두 장면 모두 화자 순환과 차례별 묶음 수신을 사용했다. 과수원은 단일 공간에서 예정된 사건을 투입하며 세계 판정 호출은 없다. 인물은 이름·정체성 첫 문장·목표 첫 문장만 남기고 성격·말투·예문·기억·관계·행동 예시는 비웠다. 원래의 회의 주제와 예산·분류표는 두 실행이 공유한다.

실행마다 생성된 사건과 대사가 달라질 수 있다. 비용은 응답의 입력·출력·캐시 사용량과 저장소 단가로 환산했고, 실패·형식 재시도도 포함했다. 역할마다 같은 모델 설정을 사용했고 각 장면의 전후 설정 지문도 일치한다. [사용량 원장 요약](usage.json)

실행 기록 화면에서 `witnessed-memory-nov08`을 검색하면 실험 묶음을 찾을 수 있다. 관측기지의 비교 대상은 `station-before`와 `station-verified`, 과수원은 `orchard-before`와 `orchard-final`이다. `station-after`는 첫 중간판, `station-final`은 재방문 문제가 드러난 두 번째 중간판이다.

관측기지는 입력이 15.0% 줄었지만 출력은 78,944개에서 88,023개로 늘었고 전체 비용은 3.2% 증가했다. 세계 계획·판정 비용만 보면 $0.10842에서 $0.13230으로 늘었다. 같은 128차례에서 흐른 장면 시간도 11분 43초에서 5분 36초로 짧아졌다. 과수원은 입력이 8.0%, 비용이 20.7% 줄었다. 각 장면의 캐시 사용량과 생성된 세계 사건도 달라졌다.

직접 대조한 네 실행의 환산 비용은 **$0.53293**였다. 중간판에는 관측기지 /1의 20차례, /2의 115차례와 과수원 /1의 48차례가 있다. 이 세 실행의 비용 $0.30241를 포함한 전체 환산액은 **$0.83535**다. 전체 한도는 $0.90이었다. 원장의 요청 1136건 중 1136건에 응답 사용량이 정산됐다.

최종판 두 실행에서 제출했던 NPC 입력 176개의 개인 기억과, API 초안을 받아 적용한 조정을 배포할 코드로 다시 계산했다. 입력 차이 0건, 조정 차이 0건이었다. 한국어 표현과 이동 목적을 보완한 ‘확인하러 갈게’, 다른 용무를 겸한 이동, ‘쇳소리가 난다’는 과거 기록 재생과 로컬 테스트에서도 확인했다. [검사와 수치](usage.json)

## 최종 관측기지의 질문과 재점검

**누가 누구에게 물었는지 대화에서 드러났다.** 51차례에 세린이 “윤 씨, 얼마나 더 쉬실 생각이세요?”라고 묻고 미루가 들었다. 52차례에 윤이 “물 한 모금 더 마시고 5분쯤 있다가 갈게요. 세린 씨도 편하게 쉬세요.”라고 답했다. 미루의 다음 질문은 55차례의 “윤, 쉬는 동안 요즘 일 말고 재밌는 일도 있었어?”였다. 56차례에 윤은 창밖 보는 재미를 이야기했고, 58차례에 미루가 무엇이 제일 눈에 띄는지 묻자 윤은 수평선 쪽 줄무늬 구름을 꼽았다. 윤과 세린은 존댓말을 쓰고 미루는 반말로 다른 이야기를 꺼냈다.

**처음 들은 보고와 본인이 확인한 결과도 구분됐다.** 나사가 조여져 소리가 줄었다는 첫 세계 판정은 작업실의 윤 혼자 받았다. 도하는 21차례에 휴게실에서 윤의 말을 들었고 53차례에 직접 살펴, “환풍기에서 약한 진동이 아직 느껴진다.”라는 판정을 혼자 받았다. 이후 세계 기록 98에서 “환풍기 진동음이 잠시 더 커진다.”가 작업실의 도하에게만 전달됐다. 바로 다음 60차례에 도하는 “환풍기 전원을 끄지 않고, 덮개와 고정 부위를 눈으로 살펴본다.”를 선택했다. 세계는 소리가 잦아들었고 덮개와 고정부에 풀림이나 손상이 보이지 않는다고 판정했다. 세린과 미루는 같은 시간에 다른 방에서 창밖 이야기를 이어갔다. [두 실행 원문과 세계 사건](comparison.md)

같은 질문이 멀리 떨어져 다시 나오는 경우는 남았다. 미루는 55차례에 “윤, 쉬는 동안 요즘 일 말고 재밌는 일도 있었어?”라고 물어 구름 이야기를 들었는데도 63차례에 “윤, 요즘 일 말고 재미 있었던 일은 있어?”라고 다시 물었다. 자동 집계가 놓친 의역 반복이다. 27차례 세린의 실제 대사에는 “저도少し 여기서 쉬었다가”처럼 일본어가 섞였다. 세계 기록 24에는 미루가 직전에 한 말을 세계가 그대로 반복한 대목도 있다. [전달 원문](transcript.jsonl)

93차례에 도하는 “좋아, 그럼 환풍기는 일단 그대로 두자. 공구나 마저 정리할게.”라고 하고 공구를 정리했다. 다만 윤은 77·87차례에 작업실에서 환풍기를 보겠다는 말을 두 번 했고, 91차례에 나사를 눈으로 확인하는 동작에 소매를 내리는 동작을 붙였다. 서로 다른 행동을 한 문장에 섞은 경우에는 다른 부분까지 잘못 지울 수 있어 통과시킨다. 도하의 공구 정리 역시 97차례에 다시 나왔다. [관측기지 128차례](comparison.md)

나래는 설명에서 비어 있는 자리를 묻고, 경자는 자신이 알아보겠다고 답하고, 민석은 금액을 대조한다. 역할을 떼고 한 문장씩 읽으면 셋 다 정중한 회의체여서 목소리 차이는 약하다. 최종판은 34차례에 홍보문 작성자가 확인되지 않았다고 답한 뒤 44차례에 같은 사실을 또 정리했다. 17차례에 부른 박복례는 이 실행의 세 참가자에 포함되지 않아 답을 들을 수 없었다. 이 장면의 기억 주입과 사후 조정은 각각 0회였으므로, 비용이나 침묵 횟수 변화만으로 이 기능이 과수원의 대화를 개선했다고 판단할 수 없다. ## 새로 확인할 수 있는 조건

테스트에서는 수신하지 못한 귓속말, 보지 못한 수리 동작, 다른 장소의 같은 장비, 아직 점검하지 않은 부위를 구분했다. 같은 장비에 “송풍기 덮개 나사가 다시 풀렸다.” 또는 “송풍기에서 쇳소리가 난다.”가 전달되면 당사자는 다시 살펴볼 수 있다. 다른 방의 라디오 소리와 ‘풀리면 알려 줘’라는 가정은 기존 결과를 지우지 않는다. 인물에게 새 통증이 생기는 현장 관찰도 마찬가지로 그 말을 들은 사람의 질문을 다시 연다.

응답 수신 확인이 유실된 뒤 새 상황을 넣고 재개하는 테스트에서는 두 수신 방식 모두 원래 호출을 한 번만 정산했다. 당시에는 중복이던 질문이 재개 후의 사건으로 소급해 살아나지 않았고, 빈 발화에 수신 처리도 생기지 않았다. [검증 코드](../../../tests/witness-memory.test.ts) · [버전별 변경 이유](../../dialogue-prompts.md)
