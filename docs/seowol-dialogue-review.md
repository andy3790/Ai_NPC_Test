# 서월 대화 개선 및 실제 API 검토 · 2026-11-06

이 문서는 첫 개선 당시의 A~F 실험 기록이다. 이후 사용자의 문체 피드백을 반영해 공통 반응 지침을 v4로 수정하고 새로운 세 인물로 추가 검토했다. 현재 실행 파일과의 관계는 [후속 문체 실험](seowol-voice-experiments.md)을 참고한다. 아래의 ‘최종 파일’은 이 첫 검토 시점의 스냅샷을 뜻한다.

## 적용 내용

원본 설정집과 운영팩을 기준으로 차유진·장세림·류태경·이하린·나연우의 실행 프로필을 만들었다. 신분·기억·이능·비용·실패 조건은 원문을 보존했다. 향후 성장 방향을 지금의 행동 목표로 넣던 부분, 가치관과 금기의 중복, 맥락 없는 단독 대사 예시를 정리했다. 구체적인 반응 패턴과 짧은 대화 맥락을 추가했다.

새 장면은 겹문의 반송 접수 마감 직전이다. 대차와 느슨한 띠는 실제로 고정할 수 있고, 접수·수리·보관·운송비 합의는 별개의 선택이다. 각 인물이 자신의 시간·돈·책임을 지키려 할 수 있게 구성했다. 원본 고지서 장면도 별도 비교 파일로 남겼다. 모든 인물을 거칠게 만들거나 미리 정한 싸움과 화해를 연기시키지는 않는다.

공통 프롬프트 `npc-lab/6`은 요청에 즉시 협조하거나 모든 질문에 답할 필요가 없음을 명확히 한다. 가치관을 설명하는 문장과 재치 있는 마무리를 매번 만들지 않는다. 주관적 의심과 세계 사실, 능력의 실제 한계와 반복적인 면책성 설명을 구별한다. 진행자 `director/2`는 즉시 대응과 직접 응답 기회를 우선하며 평가자는 비협조 자체를 오류로 취급하지 않는다.

세계 엔진에는 대사 재해설 대신 새 결과를 공개하도록 지시했다. 실제 실행에서 드러난 사물/NPC 신체 결과의 혼동과 예약 사건 조기 완료 문제를 출력 스키마 설명·검증 오류 메시지에 반영했다. 허위 결과를 통과시키는 방식으로 검증을 약화하지 않았다. 고정 접수 마감은 별도 예약 사건 대신 가상 시각과 접수 상태를 비교하도록 장면을 수정했다.

## 실행 조건과 범위

실제 OpenAI API를 사용했다. NPC는 Terra low 또는 Sol low, 진행자는 Luna low, 세계 엔진은 Luna medium이다. 독립 평가·자동 상황 발생은 껐고 매 실험은 새 NPC 세션으로 시작했다. 최종 E/F는 NPC 모델과 그 표시를 제외한 입력이 동일하다.

터미널의 직접 연결은 모델 목록 조회에서 네트워크 제한으로 실패했다. 실제 실행은 이미 열려 있던 앱의 정상 실험 화면에서 수행했다. 이 서버는 **`npc-lab/5`로 실행 중**이므로 D/E/F에서는 v6의 핵심 연기 문단을 각 NPC 역할 입력에 추가했다. 저장된 실제 입력과 코드 문단의 일치를 확인했다. E의 장면·판정 조건·기본 프로필은 최종 파일과 같고 F는 NPC 기본 모델만 다르다.

따라서 이는 **새 프로필·장면·연기 문단의 실제 검토**다. 재시작한 서버에서 v6의 전체 프롬프트·새 스키마 설명·진행자 정책을 함께 사용한 통합 실행은 아직 하지 못했다. 마지막에 추가한 능력 한계의 반복 설명 억제 문장도 다음 실행에서 확인할 항목이다. 새 코드는 빌드되어 있으며 서버 재시작 후 새 실험부터 사용한다.

| 실험 | 발화 수 | 결과 | 로컬 가격표 기준 예상 비용 |
|---|---:|---|---:|
| A · 새 장면 초안 | 1 | 사물 변화를 대상 없는 physical_effect로 출력해 정지 | $0.00531430 |
| B · 출력 유형 보강 | 3 | 120초 마감 사건을 일찍 completed로 처리해 정지 | $0.01281877 |
| C · 취소 지침 보강 | 12 | 조기 완료 오류 1회 후 수동 재개로 완주 | $0.03603100 |
| D · v6 연기 문단 추가 | 4 | 같은 예약 사건 오류로 정지 | $0.01733555 |
| E · 최종 장면, Terra low | 12 | 오류·재시도 없이 완주 | $0.03997224 |
| F · 같은 입력, Sol low | 12 | 오류·재시도 없이 완주 | $0.07795501 |

합계 44발화, 114호출, 예상 $0.18943. 실제 청구 금액이 아니라 저장된 사용량과 로컬 단가의 환산이다. 실패·재시도 호출도 포함한다. 과거 사용자 실험 비용은 포함하지 않는다. 각 모델의 최종 표본이 한 번뿐이고 진행자·세계 호출 수가 달라, 일반적인 품질 순위나 비용 배율로 해석하지 않는다.

## 실제로 달라진 점

Terra E에서 다음 협상이 이어졌다. 캐릭터에게 이 대사를 미리 준 것은 아니다.

> 장세림: “추가 운반비 10만 원은 많습니다. 7만 원으로 하죠.”
>
> 류태경: “8만 원이요. 미지급금은 오늘 입금해 주시고요. 표시등은 누가 확인합니까?”

Sol F에서는 차유진이 재촉을 거절했다.

> “확인만 삼 분쯤요. 수리 시간은 아직 못 잡아요. 지금은 재촉하지 마세요.”

그 뒤 차유진은 대사 없이 판독을 이어 갔다. 류태경은 대기 시간에 따른 추가 비용과 미지급금의 지급 약속을 요구했고, 장세림은 시간 조건을 붙여 받아들였다. 모두 같은 문제의 친절한 상담자가 되는 대신 각자 돈·시간·책임을 두고 협상하는 변화는 관찰된다. 존댓말 자체는 원작의 관계·말투와 업무 상황에 맞춰 유지된다.

## 남은 문제

- 점검·보증 이야기에 들어가면 “내용물이나 운송 안전까지 확인하는 건 아니다” 같은 설명이 반복된다. 능력 제한은 중요하지만 항상 말로 나열할 필요는 없다. 공통 프롬프트에 이 구별을 추가했다.
- 세계 엔진이 펜을 치우거나 작업을 시작했다는 사실을 굳이 중계하는 경우가 남는다. 의미 있는 외부 결과와 이미 보인 몸짓의 구분은 자연어 모델의 판단에 의존한다.
- Sol에서는 이번 표본에서 거절과 무발언 작업이 더 잘 보였지만, 모델만 바꿔 해결됐다고 판단할 수 없다. 업무 중심 장면과 말투 설정도 여전히 영향을 준다.
- 세계 엔진은 각 차례에 전체 판정 자료를 받으면서 세션도 이어 간다. E/F에서 세계 엔진 입력 누적이 크다. 이를 별도 상태와 제한된 관찰 맥락으로 바꾸는 작업은 이번 변경에 포함하지 않았다.
- 12발화 검토는 장기 캐릭터 유지, 모든 사건 분기, 최종 문제 해결을 보증하지 않는다. 원본 고지서 장면의 수정 프로필은 구조 검증만 했고 실제 모델 재실행은 하지 않았다.

## 재현 자료와 코드 검증

실험 화면에서 이름의 `[검증E]`, `[검증F]` 부분을 검색해 대화·설정·호출을 볼 수 있다. 전체 원장과 입력 스냅샷은 로컬 `.cache/seowol-live/browser-review-2026-11-06/`의 A~F 디렉터리에 내보냈다. `summary.json`에 실제 실행 ID, 비용, 모델, 최종 설정과의 차이가 있다. 비밀 키는 보고서에 기록하지 않았다.

- 관련 테스트 48개 통과: 원본 인물 사실 보존, 비공개 정보 격리, 두 모델 설정의 동일 조건, 세계 결과·지연·재시도, 평가 맥락, 진행자와 OpenAI 모의 전송.
- 타입 검사, 앱 빌드, 기본 캐릭터 팩 검증·모의 실행, 공개 파일 검사 통과.
- 최초 전체 검사에서는 150개 중 148개 통과했다. OpenAI 모의 파일의 일시적 rename 오류는 개별 재검사에서 통과했다. Windows junction 생성 검사는 환경의 EPERM 제한 때문에 완료하지 못했다. 이후 추가한 마감 취소 회귀 사례는 관련 검사에 포함되어 통과했다. 전체 검사를 모두 통과했다고 주장하지 않는다.

실행 파일과 명령은 [서월 실행 팩](../assets/seowol/README.md)에 정리했다. 원본 설정 문서와 기존 사용자 실험은 보존했다.
