# 진행자 후보 선택 재현

`selection.json`은 NPC /5·세계 /4·진행자 /2의 서월 저녁 실행에서 추출한 공개 입력이다. 후보가 둘인 정상 선택과, 장기 배제 방지로 고복만만 허용됐는데 임소진을 골라 정지한 선택을 포함한다.

`npm run director:eval`은 동결한 지침 아래 출력 스키마만 바꾼다. /2는 문자열 ID, /3은 입력 후보 enum이다. 자동 판정은 구조와 허용 ID 준수만 확인한다. 진행자 대사의 품질이나 후보 선정 규칙 자체가 자연스러운지는 이 점수로 판단하지 않는다.

입력 또는 지침을 바꾸려면 새 데이터 버전과 변경 이유를 남긴다. 실제 호출은 `--live`가 필요하다. 실패는 삭제·재시도하지 않는다.
