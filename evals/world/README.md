# 세계 판정 회귀 사례

`observations.json`은 기존 동작 중계·유효한 결과·반응 기회·마감 사례다. 최초 보류 분할도 여러 차례 재사용했으므로 이후 실험에서는 독립 holdout이 아닌 회귀 세트다.

`dialogue-processes.json`은 서월 저녁의 실제 세계 입력 4개를 동결했다. 일반 질문과 다음 노래 부탁을 물리적 반응 사건으로 새로 만들지 않는지 본다. 이미 입력에 남은 과거 대화 사건을 종료하는 것은 허용한다. 공개 사건 수 0만으로 통과를 판정하지 말고 `processes`도 읽는다.

`quiet-time.json`의 `observed_quiet_video`는 세계 /4가 76초에서 멈춘 실행의 실제 입력이다. 나머지 5개는 그 시간 경계와 기존 외부 응답 사례에서 구성한 합성 회귀다. 14초의 응답은 13→14초에 도착하고 12→13초에는 오면 안 된다. 이미 끝난 결과·단순 휴식에는 새 사건을 만들지 않는다. 처음부터 남은 시간이 8초인 타이머는 8초를 유지한다.

참고 기준은 모델 입력 밖에 둔다. 고정 입력은 새 세션에서 실행하므로 이전 세계 세션의 누적 대화까지 재현하지 않는다. 이어지는 실행을 별도로 검토해야 한다. 원문·해시·채택 이유는 [긴 대화 검토](../../docs/reviews/long-dialogue-2026-11-07/report.md)에 있다.
