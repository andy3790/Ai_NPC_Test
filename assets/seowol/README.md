# 서월 실행 팩

원본 세계관 v1.1을 바탕으로 NPC Dialogue Lab에서 사용하는 실행용 인물과 장면을 만든다. 원본 설정집·운영팩·조연 문서·축약본·기존 실험 JSON은 수정하지 않았다.

## 바로 실행하기

**갈등과 사건이 강한 장면은 [서월 사건극 6선](drama/README.md)**에서 고른다. 닫히는 문에서의 구조, 무연역 분산 구조, 고요창고 사고, 겹문의 강제 회수 대치, 통화 기록 공개, 반송 수로 탈출을 각각 독립 실험 JSON으로 제공한다. 기존 8인과 새 인물 8명을 사용하며 원본 세계관·기존 생활 장면은 유지한다.

`새 실험 → JSON 편집 → 전체 설정 → 파일 가져오기`에서 다음 파일을 선택하고 적용한다. 파일 선택이 제한된 브라우저에서는 JSON 전문을 편집기에 붙여 넣어도 된다.

| 파일 | 등장인물 | 목적 |
|---|---|---|
| [experiments/return-deadline.json](experiments/return-deadline.json) | 차유진·장세림·류태경 | 반송 접수 마감 2분 전, 움직이는 대차와 외피 표시등, 미지급 운송비와 수리 접수 책임이 겹치는 장면 |
| [experiments/return-deadline-sol.json](experiments/return-deadline-sol.json) | 동일 | 위 장면에서 NPC 모델만 Sol low로 바꾼 비교용 설정 |
| [experiments/maintenance-talk.json](experiments/maintenance-talk.json) | 차유진·이하린·나연우 | 기존 고지서 장면을 유지한 비교용 설정. 인물 프롬프트 효과를 장면 변경 효과와 나눠 확인 |

기본값은 NPC Luna low(Sol 파일은 Sol low), 진행자 Luna low, 세계 엔진 Luna medium, 30발화다. 독립 평가와 자동 상황 발생은 꺼져 있다. 추가 사건을 무작위로 넣지 않아도 현재 행동과 이해관계에서 변화가 생기는지 본다. 짧은 검토에는 발화 수를 12로 줄인다. [실제 실행 결과와 검증 범위](../../docs/seowol-dialogue-review.md)를 함께 참고한다.

## 성격과 내용 구성 비교

새 인물 백도하·임소진·고복만은 **문체 검토용 추가안**이다. 원본 인물·장소·연표에 자동 편입하지 않는다. 도하는 친한 두 사람에게 반말하고, 소진은 신경질적인 반말을 쓰며, 복만은 상대에 따라 하오체와 해라체를 쓴다. 말끝뿐 아니라 무엇을 먼저 듣고, 어떤 질문을 피하고, 어떤 물건에 집착하는지도 다르다.

| 파일 | 장면과 지침 |
|---|---|
| [experiments/strong-voices.json](experiments/strong-voices.json) | 최종 v4. 빌린 앰프의 손상을 둘러싼 세 사람의 저녁 |
| [experiments/strong-voices-dinner.json](experiments/strong-voices-dinner.json) | 최종 v4. 수리 의뢰 없이 연습 영상을 보고 식사하는 별도 저녁 |
| [experiments/strong-voices-baseline.json](experiments/strong-voices-baseline.json) | 같은 앰프 장면·인물에 이전 v2 문체 지침만 사용한 대조군 |
| [experiments/strong-voices-v3.json](experiments/strong-voices-v3.json) | 앰프 장면의 중간 수정 v3 재현 |
| [experiments/strong-voices-dinner-v3.json](experiments/strong-voices-dinner-v3.json) | 저녁 장면의 중간 수정 v3 재현 |

이 다섯 파일은 NPC Sol low, 진행자 Luna low, 세계 엔진 Luna medium, 각 18발화다. 반응 지침 비교에서는 인물·기억·세계 판정·모델을 고정했다. 실제 입력·출력과 한계는 [성격별 문체 실험 기록](../../docs/seowol-voice-experiments.md)에 정리한다. 기존 5인 실행 팩에도 최종 v4 지침을 적용했으나, 그 다섯 인물의 새 지침을 실제 API로 재검토한 결과와 혼동하지 않는다.

공통 프롬프트 `npc-lab/6`과 출력 스키마 변경은 **서버 재시작 후 새 실험**부터 사용한다. 이미 만든 실행은 자신의 프로필·세션을 보존하므로 품질 비교를 위해 재사용하지 않는다. 빌드된 서버를 사용한다면 `npm run build` 후 기존 서버를 종료하고 기존 시작 명령으로 다시 실행한다.

## 원본과 실행 자료의 관계

- `01_이면기록_서월_세계관설정집_v1.1.md`: 세계 법칙·설정의 정사 기준.
- `02_이면기록_서월_캐릭터챗_운영팩_v1.1.md`: 다섯 인물의 신분·생활·결함·경험·이능·한계 원문을 실행 프로필로 가져오는 기준.
- `03_이면기록_서월_생활형_조연_6인.md`: 당장의 생활 목표, 관계의 온도, 장면에서 결함이 생기는 방식의 설계 참고. 이번 세 인물 장면에 조연을 자동 등장시키지는 않는다.
- `seowol_maintenance_talk_v11_engine.json`: 기존 비교 장면 및 공통 세계 요약의 출처.
- `voices.json`: 기존 다섯 인물의 말투와 대화 예시. 공통 `guidance`는 이전 v2 대조군용으로 보존한다.
- `interaction.json`: 현재 공통 반응 지침 v4. 정보를 언제 말하고 어디에서 상대의 답을 기다리는지에 관한 지침이다.
- `experimental-cast.json`: 새 세 인물의 사실·관계·비공개 경험·말투 원본. `experimental-characters/`에 가져오기용 인물 JSON을 생성한다.
- `build.mjs`, `build-experiments.mjs`: 원본에서 실행 자료를 만드는 코드. `npm run seowol:build`로 인물과 실험 JSON을 재생성한다.
- `review-variants/interaction-v3.json`: 실제 중간 실험을 재현하기 위한 지침 스냅샷.

정체성·기억·능력을 새로 만들지 않고 **현재 상황에서 어떻게 선택하고 말하는가**를 구체화했다. 인물의 향후 성장 가능성은 지금 수행해야 하는 목표로 넣지 않는다. 원칙과 금기를 반복해서 넣던 부분을 정리하고, 단독 명대사 대신 짧은 대화 맥락을 제공한다. 예시는 실제 과거 대화가 아니다.

세계의 상세 법칙과 장면의 숨은 원인은 `worldEngineInstructions`에 둔다. NPC는 간추린 배경과 본인 프로필만 받으며, 다른 인물의 비밀이나 표시등의 실제 원인을 미리 받지 않는다. 독립 평가자는 판정 자료를 볼 수 있지만 이를 NPC의 지식으로 취급하면 안 된다.

## 새 장면에서 추가한 조건

대차의 마모, 8kg 용기, 느슨한 접점, 120초의 접수 마감은 **이번 실험의 에피소드 조건**이다. 원작 전체의 정사나 2024년 위조 사건의 해답으로 확정하지 않는다. 표시등의 깜박임은 내용물의 안전·위험을 증명하지 않는다. 타당한 물리적 대책은 실제로 통하고, 해결한 위험을 다시 만들지 않는다.

고정 마감은 가상 시각과 접수 여부를 비교해 판정하며 별도 예약 사건으로 등록하지 않는다. 실제 실험에서 발생한 예약 사건의 조기 완료 혼동을 피하기 위한 구성이다. 능력의 대상·거리·시간·비용은 판정 전용 자료에도 제공하되, 인물의 비공개 기억·목표는 세계 엔진에 넘기지 않는다.

| 인물 | 당장의 요구 | 충돌할 수 있는 지점 |
|---|---|---|
| 차유진 | 미검수 화물을 떠맡지 않고 마감 | 결함을 보면 손을 떼지 못하고 상대의 선택을 막을 수 있음 |
| 장세림 | 오늘 반송 접수, 비용 최소화 | 접수 확인과 과거 미지급금을 묶어 상대를 압박할 수 있음 |
| 류태경 | 인계 후 퇴근, 운송비 지급 | 추가 노동은 거절하면서도 당장 넘어질 물건에는 손이 감 |

누가 이기거나 양보할지는 정해 두지 않았다. 존댓말을 없애거나 모두 공격적으로 만드는 것도 목표가 아니다. 거절 뒤에 즉시 배려 문구를 덧붙이지 않아도 되고, 의견이 어긋난 상태에서 행동이 이어져도 된다.

## 실제 API 검토 도구

```powershell
# 설정 검증과 예상 호출 규모만 출력. API 호출 없음.
npm run seowol:live -- --spec assets/seowol/experiments/return-deadline.json

# 유료 호출을 명시적으로 허용. 격리 DB, 새 세션, 12발화씩 두 번.
npm run seowol:live -- --spec assets/seowol/experiments/return-deadline.json --label review --turns 12 --repetitions 2 --max-calls 80 --max-usd 1 --live
```

`.env`의 OpenAI 키를 사용하고 `.cache/seowol-live/`에 설정·프롬프트 스냅샷·호출·대화·사용량을 남긴다. 기존 실험 DB는 건드리지 않는다. 가격표 추정 합계가 상한에 도달하면 다음 호출을 막으며 **진행 중인 한 호출의 초과 비용까지 보장하는 과금 한도는 아니다**. 미산정 호출이 발생해도 다음 호출을 멈춘다. 자동 재시도는 하지 않는다.

문체는 자동 점수만으로 판정하지 않는다. 원본 장면/수정 프로필/새 장면을 각각 새 세션으로 실행하고 실제 대화를 읽는다. 자기 목적의 지속과 세계관 한계에 더해, 한 차례에 여러 용건을 포장하는지, 아는 정보를 즉시 공개하는지, 예상 답변까지 먼저 처리하는지, 감정을 독자에게 해설하는지, 반말만 바꾼 상담 대화로 돌아가는지를 본다. 모의 테스트 통과나 짧은 대사 비율은 자연스러운 연기를 보증하지 않는다.
